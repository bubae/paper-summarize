TL;DR

  • 문제: ##On-policy distillation (OPD)##는 LLM reasoning을 향상시키는 데 점점 많이 쓰이지만, ##parameter space에서의 학습 dynamics##는 거의 분석된 적이 없다. 기존 연구는 SFT (dense, principal-aligned updates)와 RLVR (sparse, off-principal updates)의 ##기하학적 footprint##만 알려준다. OPD는 학생 자체 rollout(=RLVR-like)을 dense token-level teacher 신호(=SFT-like)와 결합하기 때문에 어느 paradigm으로도 직접 추론 불가.
  • 해결: 3개 RQ로 OPD를 ##parameter-space 관점##에서 해부. (RQ1) ##Relaxed off-principal regime## -- OPD는 SFT보다 fewer weights에 영향, principal direction은 더 약하게 변하지만 RLVR보다는 덜 constrained. (RQ2) ##Subspace locking## -- cumulative update가 학습 초기에 빠르게 ##narrow low-dimensional channel##로 진입하여 그 안에서 수렴. (RQ3) ##Objective composition이 lock을 control## -- token sparsification과 off-policy rollout은 lock 유지, RLVR objective와 mixing하면 lock이 깨진다.
  • 왜 작동하는가: ##Three-Gate view##를 OPD에 확장 -- (G1) KL anchor (distributional anchor)는 update size 제한, (G2) pretrained model geometry는 high-curvature principal direction에서 벗어나도록 routing, (G3) bf16 precision realization이 어떤 좌표가 visibly updated인지 결정. RLVR은 sequence-level scalar advantage로 G2/G3 좁게 통과 → off-principal sparse. OPD는 token-level teacher 신호로 ##active direction set이 broaden##되지만 G1/G2 자체는 보존 → "relaxed" off-principal.
  • 비유: SFT는 등산로를 자유롭게 새로 깎는다 (principal ridge 위에 dense update). RLVR은 ##기존 등산로의 좁은 우회 샛길##만 사용 (sparse off-principal). OPD는 그 사이 ##약간 넓혀진 우회길## -- principal ridge는 피하지만 기존 path보다 ##조금 더 많은 좌표##가 update된다. 게다가 그 우회길이 학습 초기에 ##고정##되고 끝까지 그 채널만 사용한다.

핵심 기여 (Key Contributions)

  1. OPD의 parameter-space 위치 규명 (RQ1): ##bf16-aware update sparsity## (SFT 8.1% / OPD 51.6% / RLVR 77.2%), ##principal-angle rotation## (SFT >10° / OPD ~1° / RLVR <0.5°), ##spectral drift## (SFT 10⁻³ / OPD 10⁻⁴ / RLVR 10⁻⁵), ##update localization## (Update density: SFT 92.73% / OPD 46.28% / RLVR 27.76%) 4개 진단으로 OPD가 ##SFT와 RLVR 사이의 RLVR-biased relaxed off-principal regime##임을 정량 입증.
  2. Subspace Locking 발견 (RQ2): 학습 trajectory를 추적한 결과, ##OPD는 좁은 low-rank band ($\Delta W_t$의 stable rank 거의 일정)에 머무르며, SFT는 expand, RLVR은 contract##. 이는 small-update artifact가 아니라 (Frobenius norm이 RLVR보다 크면서 stable rank는 RLVR과 비슷) ##nontrivial update의 bounded spectral profile##.
  3. Early Subspace Emergence + Functional Sufficiency: 학습 매우 초기에 ##final update channel V_K(t_end)와 alignment##가 형성됨을 ##subspace similarity## (Eq.9)로 보임. 학습 ~20% 시점의 top-16 right singular subspace로 gradient projection을 ##constrain##해도 OPD 성능은 거의 unchanged인 반면 SFT는 substantial degradation. ##Lock이 functionally sufficient##하다는 의미.
  4. Objective Composition이 Lock의 1차 control axis (RQ3): 3가지 perturbation 비교: (a) token sparsification (top-KL/random 25%/50%) → rank trajectory 보존 (scale만 변함), (b) off-policy rollout (teacher가 rollout) → rank trajectory 보존, (c) ##objective interpolation $A^{(\alpha)} = \alpha A_{\text{OPD}} + (1-\alpha) A_{\text{RLVR}}$ → α=0.05/0.01에서 rank dynamics 깨짐##. ##즉 lock은 runtime이 아닌 objective 자체에 sensitive##.
  5. Three-Gate Account의 OPD 확장: RLVR의 Three-Gate (Zhu et al., 2025)를 ##signal granularity 차원으로 relax##. Gradient $g = \sum_t a_t \phi_t$에서 RLVR은 $a_t = A(y)$ (sequence-level scalar) 공유, OPD는 $a_t$가 token마다 teacher-student disagreement에 따라 ##heterogeneous## → covariance가 broaden되어 OPD가 더 많은 direction을 활용하지만 G1/G2 anchor는 유지. "##OPD는 RLVR의 on-policy 구조를 유지하되 scalar credit signal을 dense token-level supervision으로 대체##"라는 단일 문장 mechanism.
  6. Robustness across teacher/student/data: Qwen3-8B (controlled 비교) 외에 Qwen3-4B-T8B, T14B, T32B, 14B-T32B (student/teacher scale 변화), Qwen3-30B-A3B MoE teacher, code domain (DeepCoder/LiveCodeBench v5)에서도 ##sparsity 48.6%~57.1% 일관##. OPD-specific 패턴이 한 setting의 우연이 아님.
  7. 실용적 implication: 향후 OPD 알고리즘은 ##token coverage나 rollout generation보다 objective-induced update geometry를 regulate## 해야 함. Locked update channel을 monitor하고 그 channel을 보존하는 design이 OPD를 ##stable, interpretable, transferable## 하게 만든다.

1. Introduction

대형 reasoning 모델(LRM)은 post-training으로 큰 진보를 이뤘다. 주류는 (a) SFT (offline demonstration, cross-entropy), (b) RLVR (verifiable reward 기반 RL). 최근 ##On-policy distillation (OPD)##가 보완 paradigm으로 부상 -- ##학생 자기 자신의 sampled rollout##에서 학습하되 ##stronger teacher의 dense token-level guidance## 하에 학습.

그러나 OPD의 ##parameter-space dynamics##는 거의 알려지지 않았다. 기존 분석 (Liu et al., 2026; Mukherjee et al., 2025; Zhu et al., 2025)이 보여준 SFT-RLVR 기하학적 dichotomy:

방법Update 특성Spectral 보존
SFTDense, principal-aligned -- pretrained spectral structure를 ##distort##약함
RLVRSparse, off-principal -- ##spectrum 보존##강함
OPDSFT-like (dense token guidance) + RLVR-like (on-policy + policy-gradient)?

OPD는 두 paradigm의 특징을 동시에 갖고 있어 ##어느 쪽 trajectory로도 직접 추론 불가능##. 본 논문은 3 RQ로 답한다:

  • RQ1: OPD는 SFT-RLVR parameter-space spectrum의 어디에 위치하는가?
  • RQ2: OPD는 학습 중 어떤 ##intrinsic update trajectory##를 따르는가?
  • RQ3: 어떤 component가 그 trajectory를 control하는가?

핵심 발견 3개 (Figure 1):

  1. Relaxed off-principal regime: OPD는 SFT(over-principal)와 RLVR(off-principal) 사이지만 RLVR 쪽으로 bias됨
  2. Early subspace lock: 학습 초기 OPD가 ##narrow low-dimensional subspace##로 진입하고 끝까지 거기 머무름; SFT는 expand, RLVR은 late contraction
  3. Objective composition controls lock: Lock은 token / rollout perturbation에는 robust, objective composition에는 sensitive

3. Locating OPD in Parameter Space

OPD가 SFT-like distillation과 RLVR-like online optimization 사이의 어디인지 명확히 하기 위해, ##Zhu et al. (2025) diagnostic suite##를 활용:

3.1 Parameter-Space Diagnostics

$W_0$ = initialization, $W_+$ = post-training 후 weight, $\Delta W = W_+ - W_0$.

Update sparsity

bf16-visible update convention: scalar weight $w_i, \hat{w}_i$가 다음 만족하면 unchanged로 간주:

$$|\hat{w}_i - w_i| \leq \eta \max(|w_i|, |\hat{w}_i|), \quad \eta = 10^{-3}$$

bf16-aware update sparsity:

$$\text{sp}(W_0, W_+) = 1 - \frac{1}{n}\sum_{i,j} \mathbf{1}[W_{+, ij} \not\approx_\eta W_{0, ij}] \tag{1}$$

큰 값 = fewer visible weight changes.

Principal-angle rotation

Dominant singular subspace의 rotation을 ##principal angle## (Eq.2)로 측정:

$$\cos\theta_i(U) = \sigma_i(U_{0,k}^\top U_{+,k}), \quad \cos\theta_i(V) = \sigma_i(V_{0,k}^\top V_{+,k}) \tag{2}$$

여기서 $U_{\cdot, k}$, $V_{\cdot, k}$는 top-$k$ left/right singular vector. ##작은 angle = pretrained dominant subspace 강한 보존##. 직관적으로 말하면, $W_0 = U \Sigma V^\top$의 주축이 학습 후 얼마나 회전했는지를 1단위로 측정.

Spectral drift

Normalized Spectral Shift (NSS):

$$\text{NSS}(W_0, W_+) = \frac{\|\sigma(W_+) - \sigma(W_0)\|_2}{\|\sigma(W_0)\|_2} \tag{3}$$

$\sigma(\cdot)$는 descending singular value. 작은 NSS = stronger spectral preservation.

Update-mask overlap

bf16 update mask $M = \{(i,j): \text{bf16}(W_+)_{ij} \neq \text{bf16}(W_0)_{ij}\}$.

  • $M_{\text{princ}}$ = $W_0$의 rank-$k$ SVD reconstruction에서 ##top-$\alpha$ fraction by magnitude## (high-curvature region proxy)
  • $M_{\text{low}}$ = bottom-$\alpha$ fraction of entries by $|W_0|$ (low-magnitude region)
  • Overlap: $\text{Overlap}(M_\star, M) = |M_\star \cap M| / |M|$

Random baseline = $\alpha$. Sub-random with $M_{\text{princ}}$ = depletion from principal weight, super-random with $M_{\text{low}}$ = concentration in low-magnitude region.

3.3 A Relaxed Three-Gate Account of OPD

Zhu et al. 2025의 Three-Gate (RLVR이 off-principal이 되는 이유):

  1. Gate I (Distributional anchor): KL-regularized/trust-region이 update size 제한 -- 매 step이 pretrained model을 자유롭게 rewrite하지 못함
  2. Gate II (Model geometry): Bounded step에서 structured loss landscape이 ##high-curvature principal direction에서 멀어지고 lower-curvature spectrum-preserving region##으로 routing → off-principal
  3. Gate III (Precision realization): bf16 precision이 ##어떤 좌표가 visibly update##되는지 결정 -- sub-threshold micro-update는 stored weight에 안 보임

OPD에 대한 relaxation: OPD는 같은 gated 구조를 보존하되 ##signal granularity##만 다름. RLVR은 token gradient를 sequence-level scalar reward로 묶음, OPD는 ##dense token-level teacher distribution##으로 더 dense한 descent direction 제공.

Signal granularity: Token score $\phi_t = \nabla_\theta \log p_\theta(y_t | x, y_{<t})$. Post-training update 일반화:

$$g = \sum_{t=1}^T a_t \phi_t \tag{4}$$
  • RLVR: $a_t = A(y)$ shared across tokens (sequence-level scalar)
  • OPD: $a_t$가 token마다 ##local teacher-student disagreement##에 따라 varies

OPD는 RLVR의 ##on-policy form 유지##하되 ##scalar credit signal을 dense token-level supervision으로 대체##.

Gate I (distributional anchor): OPD remains anchored. Local quadratic budget 하에서 update norm $\|\Delta W\|_F \leq \sqrt{2\delta_W / \mu_W}$ (Eq.5). 차이는 budget 사용 방식 -- RLVR은 sequence-level reward signal로, OPD는 teacher-token distribution으로 ##denser descent direction##을 anchored region 내에서 제공 → ##larger effective update than RLVR while remaining far below SFT-style unconstrained rewriting##.

Gate II (model geometry): Bounded update가 여전히 pretrained model geometry에 의해 shape됨. OPD의 relaxation은 update covariance에서 나타남:

$$\mathbb{E}[gg^\top] = \sum_{t,t'} \mathbb{E}[a_t a_{t'} \phi_t \phi_{t'}^\top] \tag{6}$$

RLVR은 모든 token score를 ##shared scalar##로 couple, OPD는 ##heterogeneous token coefficients##로 broaden.

Gate III (precision realization): bf16 realization unchanged. 좌표가 visibly updated가 되려면 $|\Delta W_{ij}| \gtrsim \frac{1}{2}\text{ULP}_{\text{bf16}}(W_{0,ij})$ (Eq.7). OPD의 larger geometry-constrained update가 ##더 많은 좌표가 bf16 realization threshold를 통과##하게 만들어 sparsity ↓, off-principal bias 유지.

Implication: OPD는 relaxed off-principal regime을 차지 -- ##RLVR-like geometry-steered##, 그러나 ##SFT-like dense teacher supervision으로 less selective##. ##OPD recipe는 token-level supervision density보다 update geometry를 regulate해야 함.##

4. Subspace Locking in OPD

RQ2: OPD의 endpoint property뿐 아니라 ##training trajectory##도 distinct한가? Cumulative update $\Delta W_t = W_t - W_0$를 checkpoint별로 추적.

4.1 A Low-Dimensional Update Band (Figure 4)

각 matrix에 대해 ##stable rank## (Eq.8):

$$\text{srank}(\Delta W_t) = \frac{\|\Delta W_t\|_F^2}{\|\Delta W_t\|_{\text{op}}^2} \tag{8}$$

Algebraic rank와 달리 ##scale-aware##, "few dominant singular direction이 update energy를 carry"하는 정도 측정.

관찰:

  • Figure 4(a) Stable rank: ##OPD는 narrow band (~20-30) 내에서 거의 일정##; SFT는 progressively expand (45→75); RLVR은 contract (70→15)
  • Figure 4(b) Frobenius norm $\|\Delta W_t\|_F$: ##OPD는 RLVR보다 substantially larger## update accumulate하면서도 stable rank는 비슷 → "small-update artifact" 가설 기각. OPD가 진짜로 ##non-trivial update의 bounded spectral profile##을 보임
  • Figure 4(c) Hill alpha (spectral tail estimator): OPD evolve mildly, SFT increases sharply, RLVR decreases over training -- auxiliary 확인

이로써 OPD는 SFT와 RLVR의 ##temporal interpolation 아님##. 학습 초기에 low-dimensional regime으로 진입하여 ##그곳에 머문다##.

4.2 Stability and Functional Sufficiency

Early subspace emergence (Figure 5)

Low dimensionality alone이 lock을 의미하진 않는다 (다른 low-rank subspace를 rotation할 수도). 따라서 ##final low-dimensional update channel emerge time##을 test:

$$\text{Sim}_K(t, t_{\text{end}}) = \frac{1}{K}\|V_K(t)^\top V_K(t_{\text{end}})\|_F^2 \tag{9}$$

$V_K(t)$는 $\Delta W_t$의 top-$K$ right singular subspace. 1에 가까우면 update가 final update channel의 singular direction을 이미 사용 중.

관찰: ##OPD는 첫 measured checkpoint부터 final $V_{16}$ subspace와 align##; SFT, RLVR은 gradually 수렴. ##OPD의 low-dimensional channel은 late assemble이 아니라 early emergence##.

Functional sufficiency (Figure 6)

이 channel이 descriptive only인가, sufficient for learning인가?

실험 의도: ##K=16## (early stable rank scale, slightly below effective dimension)으로 ##stringent bottleneck## 부여. 학습 ~20% 시점에서 $V_{16}$ 추출 → 이후 학습 시 매 gradient $g$를 ##$g \leftarrow g V_{16} V_{16}^\top$##로 project (Eq.10) → 이 rank-16 constraint 하에서 OPD vs SFT 학습.

결과:

  • ##OPD는 rank-16 bottleneck 하에서 essentially unchanged## (AIME2024 avg@8 ~plain과 동일)
  • ##SFT는 매칭 window에서 substantial degradation##
  • 같은 패턴이 추가 reasoning benchmark (AMC2023, AIME2025, Minerva, Beyond AIME)에서도 hold (Appendix F, Figure 8)

이 결과가 뒷받침하는 주장: ##Locked update channel은 OPD의 학습에 functionally sufficient##; 같은 constraint가 SFT를 망가뜨림으로써 sufficiency가 ##projection dimension의 generic property가 아니라 OPD-specific##임을 confirm. ##미래 OPD 구현은 low-dimensionality를 post-hoc spectral statistic이 아닌 monitored & exploited channel로 다뤄야 한다.##

5.1 Runtime Perturbations Preserve the Lock

(a) Token sparsification (Figure 7a)

Sample마다 binary mask $m_t \in \{0, 1\}$. Top-KL retention: token을 sampled-token student-teacher log-probability gap $r_t = \log\pi_\theta(a_t|s_t) - \log\pi_T(a_t|s_t)$로 ranking, top $\rho$ fraction 유지 -- student가 teacher 대비 over-confident인 token 선택. Random retention: $\rho \in \{0.25, 0.5\}$ uniform.

Compensation: $\tilde{r}_t = T m_t r_t / \sum_\tau m_\tau$.

결과: 모든 sparsified variant가 OPD baseline의 stable-rank trajectory를 ##closely track##. ##25% retention beyond는 update scale을 더 변화시키지만 spectral shape는 변화 ⇒ low-rank profile은 small set of high-KL token에 localize되지 않음##.

(b) Off-policy rollout (Figure 7b)

$y \sim \pi_T(\cdot | x)$ (teacher generates rollouts), student가 training forward pass에서 teacher-generated token의 log-probability 계산. ##Training objective는 pure OPD KL distillation 유지##. Importance-ratio clipping $\epsilon = 1.0$ (clipping inactive). Qwen3-32B teacher rollout, sglang router + 2 teacher replica.

결과: Off-policy OPD가 ##modestly larger update norm##을 produce하지만 stable-rank trajectory는 ##nearly unchanged##. ##Rollout-policy 변화에 robust##.

5.2 Objective Mixing Changes Rank Dynamics (Figure 7c)

Advantage level interpolation:

$$A_i^{(\alpha)} = \alpha A_{i, \text{OPD}} + (1-\alpha) A_{i, \text{RLVR}} \tag{11}$$

$A_{i, \text{OPD}} = -r_i$ (sampled-token teacher-correction), $A_{i, \text{RLVR}}$ = GRPO advantage from math accuracy reward broadcast to response tokens. $\alpha \in \{0.75, 0.50, 0.25, 0.05, 0.01\}$.

결과:

  • OPD-dominant mixture (α 큰 값) → OPD-like stable-rank trajectory 유지
  • ##α = 0.05/0.01 (OPD weak)에서 trajectory가 deviation##, 다른 spectral regime으로 진입
  • Token sparsification이나 off-policy generation과 달리, ##gradient source 자체를 변경##

Mechanistic view: OPD gradient = $g_{\text{OPD}} = \sum_t J_t^\top \delta_t$, $\tilde{g}_{\text{OPD}} = \sum_t m_t J_t^\top \delta_t$. Token gradient가 dominant update subspace 공유하면 ##masking은 second moment를 primarily rescale##:

$$\mathbb{E}[\tilde{g} \tilde{g}^\top] \approx c \mathbb{E}[g_{\text{OPD}} g_{\text{OPD}}^\top] + \text{noise} \tag{13}$$

Off-policy rollout은 sampling distribution을 변경하지만 teacher-token gradient source 동일. Objective mixing은 source 자체 변경:

$$g_\alpha = \alpha g_{\text{OPD}} + (1-\alpha) g_{\text{RLVR}}, \quad \Sigma_\alpha \approx \alpha^2 \Sigma_{\text{OPD}} + (1-\alpha)^2 \Sigma_{\text{RLVR}} + \alpha(1-\alpha) \Sigma_{\text{cross}} \tag{14}$$

OPD term이 weak해지면 ##dominant covariance geometry 변경##. ##Lock은 objective-sensitive, not runtime-induced.##

Implication: ##효과적인 OPD recipe는 token coverage나 rollout generation이 아니라 objective-induced update geometry를 regulate##해야 한다.

6. Discussion & Conclusion

본 분석은 OPD를 ##distinct parameter-space regime##으로 식별 -- SFT와 RLVR 사이의 simple endpoint interpolation이 아니다. OPD는 relaxed off-principal region을 차지하고, training trajectory가 ##subspace locking## 표현 -- cumulative update가 학습 매우 초기에 ##small, persistent low-dimensional channel##로 진입하여 그곳에서 학습.

이 발견들은 ##미래 OPD 알고리즘의 guiding principle##을 제시:

  • Design OPD as geometry control, not merely denser token supervision
  • Locked update channel을 monitor하고 ##objective composition을 primary lever##로 사용 (geometry drift 시), token selection / rollout policy / teacher scale은 update geometry에 미치는 효과를 통해 tune
  • 이런 ##geometry-aware control##이 OPD를 stable, interpretable, transferable하게 만들 수 있다 -- learning을 지원하는 update channel을 보존하면서 unnecessary parameter-space drift를 회피

Limitations

  • 분석은 controlled Qwen3-family reasoning setting에 focus -- 다른 model family, modality, task distribution에서 geometry가 다를 수 있음
  • Diagnostic은 stored checkpoint의 parameter-space trajectory를 characterize -- ##Three-Gate account와 covariance analysis는 evidence-consistent mechanistic explanation##으로 봐야 하며 complete causal/formal theory 아님

비판적 분석

강점

  • OPD에 대한 첫 parameter-space 진단: 기존 OPD 연구는 ##empirical failure mode + scaling recipe + multi-teacher distillation + training efficiency##만 다뤘음. ##Parameter space에서의 위치와 trajectory##를 정량적으로 다룬 첫 시도.
  • Three-Gate framework의 우아한 확장: Zhu et al. 2025의 RLVR account를 ##signal granularity 차원으로 relax##만 해서 OPD의 모든 행동(less sparse, broader covariance, similar off-principal direction)을 단일 mechanism으로 설명. 우아한 narrative.
  • Subspace lock의 functional sufficiency 입증: Rank-16 projection을 OPD와 SFT 모두에 가했을 때 ##OPD만 unchanged##. ##Lock이 단순 spectral shape 관찰이 아니라 학습에 sufficient한 channel##임을 보임. 강한 결과.
  • Controlled experimental design: Token sparsification, off-policy rollout, objective mixing 3가지를 ##single factor만 변경##하여 ##lock의 control axis##를 분리. Mechanistic view (Eq.13, 14)로 왜 이 결과가 나오는지 설명.
  • Robust across student/teacher/data: Qwen3-8B controlled 외에 4B-T8B/T14B/T32B, 14B-T32B, MoE teacher (Qwen3-30B-A3B), code domain까지 sparsity 48.6-57.1%로 일관. Single-config 우연 아님.
  • Detailed reproducibility: Tables 2-7로 모든 hyperparameter 공개; controlled SFT anchor iter_0005375 공유; bf16 convention $\eta = 10^{-3}$, principal angle rank $k=512$, mask $r=64, \alpha=0.5$ 등 명시.
  • Implications가 actionable: "monitor locked channel + use objective composition as primary lever"는 ##추상적 통찰이 아니라 OPD 시스템 설계자가 바로 시도할 수 있는 권고##.

한계와 의문점

  • Qwen3 단일 family로 한정: 저자도 인정. Llama, DeepSeek, Mistral 등 다른 family에서 동일 패턴이 나오는지 미검증. Backbone-specific spectral structure가 결과에 얼마나 dependent한지 unclear.
  • Math+Code 도메인 한정: General instruction following, factuality, multi-modal task에서 OPD geometry가 어떻게 변하는지 모름. Verifiable reward와 token-level supervision이 가장 깨끗한 setting에서만 분석한 것이 일반화 한계.
  • Rank-16 projection이 functional sufficient인 이유의 이론 부재: 왜 16인지, top-K 선택 알고리즘이 다른 K에서도 같은 결과인지. Figure 6은 K=16만 보여줌. K=8, 32, 64에서 어떻게 변화하는지 ablation 부재.
  • Trajectory metric이 cumulative $\Delta W_t$ only: Stable rank, Frobenius norm, Hill alpha는 모두 cumulative update의 spectral 성질. ##Per-step gradient의 spectral shape##나 ##trajectory의 곡률##은 보지 않음. "lock"이 진짜로 dynamics인지 cumulative endpoint statistic인지 더 깊은 검증 필요.
  • "Lock"이라는 metaphor의 강도: Subspace similarity Sim_K(t, t_end) 가 OPD에서 ~0.7 from start, ~1.0 by end. 그러나 SFT/RLVR도 ##gradually 수렴##. "OPD는 lock, SFT/RLVR은 not lock"의 binary 차이가 정성적인지 정량적 threshold가 있는지 명확하지 않다.
  • 학습 step 수 차이의 영향: SFT 5K / OPD 300 / RLVR 1K step. Step 수가 다르므로 cumulative $\Delta W$의 norm/rank trajectory를 직접 비교하는 것이 fair한지 의문. Step-rescaled comparison 부재.
  • Objective interpolation의 αα값 선택: α ∈ {0.75, 0.50, 0.25, 0.05, 0.01} 중 ##0.05, 0.01에서만 break## -- 즉 OPD signal이 95%+ 유지되어야 lock 유지. 이는 "OPD는 robust"인지 "거의 모든 mixing에서 lock 유지"인지 ambiguous.
  • Causality vs correlation: 저자 본인도 Limitations에서 "evidence-consistent mechanistic explanation"이라 명시. ##이 lock이 OPD 성능 향상의 cause인지 byproduct인지##는 불명. Lock을 의도적으로 깨뜨렸을 때 reasoning benchmark에서 어떤 성능 변화가 나오는지의 controlled study 부재.
  • Teacher scale의 영향 미세분석 부재: 4B→T8B, T14B, T32B에서 sparsity 50.3/51.1/51.7로 ##거의 동일##. 즉 teacher scale은 sparsity를 거의 변화시키지 않음. 그러나 ##stable rank trajectory##나 ##functional sufficiency## 측면에서는 어떤 차이가 있는지 미보고. Teacher scale이 정말로 update geometry에 무관한가?
  • Practical OPD recipe로의 직접 가이드 부족: "objective composition을 primary lever로"라는 조언은 추상적. 실무자가 어떻게 정확히 objective를 monitor하고 (어떤 metric, 어떤 threshold) 어떻게 intervene할지에 대한 구체적 알고리즘이나 sample code는 future work로 미뤄짐.
  • "Three-Gate"가 Zhu et al. 2025의 비유적 framework: 본 논문은 이 framework를 빌려서 OPD를 설명하는데, ##framework 자체의 정량적 검증##은 본 논문에서 다루지 않음 (그게 본 논문 목표는 아님). 그러나 framework가 OPD에 적용될 때의 ##새로운 가정##이나 ##자유 매개변수##는 명시적으로 분석되지 않음.

Key Takeaways (이 논문에서 가져갈 것)

  1. OPD의 "Geometric Identity": SFT(over-principal, dense, distort)와 RLVR(off-principal, sparse, preserve) 사이의 ##relaxed off-principal regime, RLVR-biased##. Sparsity 51.6%, principal angle ~1°, NSS 10⁻⁴는 OPD의 4가지 정량적 signature.
  2. Subspace Lock = OPD의 학습 dynamics 본질: Cumulative update가 ##학습 초기 (~20% 시점)에 final low-rank channel과 align##되고 그 안에서 학습이 끝까지 진행. SFT는 expand, RLVR은 contract -- OPD만 lock. 이는 ##학습 trajectory의 distinct identity##.
  3. Three-Gate에 Signal Granularity 차원 추가: RLVR의 KL anchor + model geometry + bf16 realization이 보존되되, ##scalar advantage를 dense token coefficient로 대체##하면 active direction set이 broaden되고 update가 less selective. ##다른 RL 변형 분석에도 동일 framework 적용 가능##.
  4. Lock의 Sensitivity Axis 식별: Token sparsification (top-KL/random 25/50%) → ##scale만 변경##; Off-policy rollout (teacher generates) → ##거의 unchanged##; ##Objective mixing은 lock break (α≤0.05에서)##. ##OPD 시스템의 primary tuning lever는 token coverage나 rollout이 아니라 objective composition##.
  5. "Functional Sufficiency"의 Rigorous Test: Rank-16 projection을 ##학습 ~20% 시점에서 freeze##하고 이후 학습을 그 subspace에 constrain. OPD는 거의 영향 없음, SFT는 major degradation. ##학습된 channel이 서술적 fact가 아니라 학습에 충분한 conduit##임을 보여주는 ##강한 실증 디자인##.
  6. OPD 설계 원칙: Geometry Control First: 미래 OPD 알고리즘은 (a) ##locked update channel의 stable rank를 monitor##, (b) drift 시 ##objective composition을 primary lever##로, (c) token selection / rollout policy / teacher scale은 ##update geometry에 대한 effect를 통해## tuning. 추상적 조언이 아닌 ##actionable design framework##.
  7. Reasoning RL 연구의 새 차원: 그동안 RL 분석은 reward shaping, advantage estimator, exploration에 집중. 본 논문은 ##weight space에서 학습 alg의 footprint##라는 새 분석 차원을 보여줌. 후속 연구가 PRO, GRPO 변형, DAPO 등을 같은 방식으로 위치시키면 ##post-training algorithm zoo의 geometry map##이 가능.
  8. Spectral Geometry as Quality Signal: Stable rank trajectory가 일정하게 유지되면 healthy OPD, drift하면 objective composition 문제. ##재훈련 metric으로 reward나 loss 외에 weight geometry 추가 가능##. 모델 production pipeline에서 quality assurance에 활용 가능.
