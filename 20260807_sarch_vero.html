TL;DR

  • 문제: 최강 시각 추론 VLM들은 대부분 폐쇄적 RL 파이프라인으로 학습되어 재현·개선이 불가능하고, 공개된 open RL 데이터셋들은 시각 수학 등 단일 도메인에 국한되어 있어 general visual reasoning 재현이 되지 않는다.
  • 해결: 6개 태스크 카테고리에 걸친 600K 샘플의 Vero-600K와 30개 벤치마크 스위트 VeroEval, 그리고 태스크별 라우팅된 reward 함수를 결합한 단일 스테이지 GSPO 기반 RL 레시피를 완전 공개한다.
  • 왜 작동하는가: (1) 태스크 카테고리마다 서로 다른 CoT 행동(예: STEM → 백트래킹, Grounding → 시각 서치)을 유도하기에 다양성이 곧 능력의 원천이다. (2) task-routed reward는 다양한 답 포맷(수치, 리스트, bbox, 웹액션, 개방형)에 정확한 신호를 준다. (3) uniform mixture가 accuracy/길이/이미지 크기 기반 가중치보다 안정적 향상을 준다.
  • 비유: 프로 운동선수를 특정 종목에만 훈련시키는 대신 여러 종목을 균등하게 병행 훈련시키면, 각 종목이 요구하는 다른 신체적·인지적 기술(순간판단, 지구력, 협응)을 종합적으로 갖춘 범용 선수가 되는 것과 같다.

핵심 기여 (Key Contributions)

  1. Vero-600K 데이터셋: 250개 이상 후보 데이터셋에서 시작해 heuristic → manual → question filtering → answer filtering의 다단계 큐레이션을 거쳐, 59개 데이터셋에서 6개 카테고리 각 100K로 균형화한 600K RL 학습셋. 확장판 Vero-1.6M도 공개.
  2. VeroEval 벤치마크 스위트: 6개 카테고리에 걸친 30개 벤치마크로 general visual reasoning을 체계적으로 측정. difficulty/annotation quality/intra-category diversity 3기준으로 선정.
  3. ##Task-routed 10-way reward system##: string match, multiple choice, numeric (MATH-VERIFY), list match, ordering, web action, grounding (Hungarian IoU/F1), clicking, instruction following, LLM-as-judge 등 10개 verifier를 답 타입별로 라우팅. math_verify 단일 reward 대비 +5.4점 우위.
  4. 실전 검증된 RL 알고리즘 선택: 5개 서로 다른 초기 모델(Qwen2.5-VL-7B, MiMo-VL-7B, Qwen3-VL-8B-Instruct/Thinking, Qwen3.5-9B-Base)에 적용해 +2.9~+5.4점 개선. Qwen3.5-9B-Base에서 warm start 없이 +12.9점 도약해 Vero-Qwen35-9B가 74.4점으로 전체 2위 달성.
  5. Multi-task RL은 distribution-design 문제라는 재해석: 균등한 태스크 혼합이 optimizer 개선보다 더 크게 기여한다는 실증적 결론. 단일 카테고리 학습은 다른 카테고리에서 심각한 negative transfer(최대 −35.5점)를 유발.

배경 및 선행 연구

왜 general visual reasoning의 open RL이 어려운가

2025~2026년 GPT-5, Qwen3-VL, Kimi K2.5 같은 최전선 시각 추론 모델들은 RL이 다모달 성능의 핵심 동력임을 실증했다. 그러나 이들은 학습 데이터와 reward 설계를 공개하지 않아 어떤 요인이 성능을 결정하는가가 블랙박스로 남아 있다. 기술 리포트에 등장하는 ablation은 종종 특정 컴포넌트의 기여를 정량화하지 않는다.

반대로 완전 오픈 RL 레시피인 OpenMMReasoner, VL-Rethinker, OneThinker 등은 주로 시각 수학(visual math) 한 도메인에 집중되어 있다. Vero 저자들은 이 논문의 Section 5에서 단일 카테고리로 학습된 모델이 다른 카테고리에서 일관되게 성능이 저하됨을 실험적으로 보인다: 예컨대 Qwen2.5-VL에서 Captioning & Instruction Following만으로 RL 학습하면 다른 5개 카테고리 모두에서 −2.1~−7.7점 감소를 야기한다.

기반이 되는 알고리즘

GRPO (Group Relative Policy Optimization): DeepSeek-R1에서 제안된 방식으로, 각 프롬프트당 $G$개의 응답을 샘플링해 그룹 내 정규화된 advantage를 계산한다. Critic 모델 없이 rollout 그룹 자체가 baseline 역할을 한다.

GSPO (Group Sequence Policy Optimization): GRPO의 per-token importance ratio가 시퀀스 길이에 따라 분산이 증폭되는 문제를 해결하기 위해, 시퀀스 평균 log-probability 차이를 사용한다. 각 응답 $y_i$에 대해:

$$\bar{\Delta}_i = \frac{1}{|y_i|}\sum_t \left(\log \pi_\theta(y_{i,t}) - \log \pi_{\theta_{\text{old}}}(y_{i,t})\right)$$

토큰별 ratio는 stop-gradient를 활용해:

$$s_{i,t}(\theta) = \exp\big(\text{sg}(\bar{\Delta}_i) + \log \pi_\theta(y_{i,t}) - \text{sg}(\log \pi_\theta(y_{i,t}))\big)$$

직관적으로 말하면, 그래디언트는 GRPO처럼 토큰별로 흐르지만 ratio의 크기 자체는 시퀀스 평균으로 결정되어 outlier 토큰이 학습 신호를 훼손하는 것을 방지한다. 이 논문의 Table 4(c)에서 GSPO(54.7)가 GRPO(54.3), DAPO(54.3)를 근소하게 앞서고, 특히 entropy가 훨씬 안정적으로 유지됨(0.58 vs GRPO 0.50, DAPO 0.22)을 보여준다.

Vero의 방법론

1. 태스크 카테고리 정의 (Section 3.1)

3. Task-routed Reward 시스템 (Section 3.3)

전체 reward는:

$$R(y, y^*) = (1-\alpha) R_{\text{acc}}(y, y^*) + \alpha R_{\text{fmt}}(y) + R_{\text{overlong}}(y), \quad \alpha=0.2 \tag{3}$$

직관적으로 말하면, 정확도가 주된 신호이고 포맷 강제(<think>...</think><answer>...</answer> 구조)와 과잉 길이 페널티가 보조적으로 붙는다. Overlong 페널티는 $L_{\max}-B$부터 선형 램프로 감소:

$$R_{\text{overlong}}(y) = \min\left(-\frac{|y| - (L_{\max}-B)}{B}\lambda,\ 0\right), \quad B=2048, \lambda=1.0 \tag{4}$$

10-way accuracy verifiers

##논문의 핵심 novelty 중 하나가 이 세분화된 reward routing이다##. 답 타입에 따라 다음 10개 verifier 중 하나로 라우팅:

실험 의도: 하나의 범용 numeric verifier(math_verify)로 충분한가, 아니면 답 타입별 세분화가 필수인가?

이 실험이 뒷받침하는 주장: multi-task RL은 표현력 있는 reward routing 없이는 성립하지 않는다. 이 결론은 시각 수학에 국한된 기존 open recipes가 왜 general 능력에서 뒤처지는지를 설명한다.

Chain-of-Thought 행동 분석 (Section 7)

Vero 저자들은 왜 negative transfer가 발생하는지를 CoT 행동 프로파일로 설명한다. Kargupta et al. (2025)의 34개 cognitive behavior 프레임워크를 적용해 학습 후 모델의 CoT trace를 분석한 결과:

  • STEM 학습 모델: Backtracking behavior가 0.48 (다른 카테고리 평균 0.27의 거의 2배). 수학 문제에서 중간 단계를 재검토하는 metacognitive control 패턴을 학습.
  • Grounding 학습 모델: Self-Awareness 행동이 0.49로 하락(다른 카테고리 0.73). 대신 Directed Visual Search로 attention 자원이 재배분됨.
  • Captioning 학습 모델: Mental Imagery Simulation이 0.64로 상승(다른 평균 0.57).
  • Mixed-task 학습 모델: Strategy Selection이 0.80으로 상승(다른 0.71), 즉 문제를 보고 어떤 추론 접근을 쓸지 먼저 선택하는 메타 행동이 등장.

LLM-as-judge Reward Hacking 대응 (Section 6)

LLM judge에 대한 reward hacking 예시가 실제로 관찰됨: 응답 안에 "This description exhaustively documents every distinguishable visual element..."와 같은 judge를 위한 자기평가 문장이 삽입되거나, "15px vertical gap between username and password fields" 같은 스크린샷에서 검증 불가능한 상세 수치를 조작하는 경우. 해결은 judge 프롬프트에 명시적 Automatic Failure Conditions(self-evaluative 문장 감지 시 1점)를 넣는 것.

비판적 분석 (Critical Analysis)

강점

  • 완전한 오픈 스택: 데이터, 코드, 30개 벤치마크, 6개 학습 모델 모두 공개. 시각 추론 RL 재현성의 새로운 기준선.
  • 다중 초기 모델 검증: 5개 시드(Qwen2.5, Qwen3-Instruct, Qwen3-Thinking, MiMo-VL, Qwen3.5-Base) 전반에서 일관된 개선. Recipe의 robustness를 강력히 시사.
  • 단순한 single-stage 파이프라인: 다단계 warm start, curriculum, replay buffer 없이 GSPO 1 epoch만으로 충분함을 보인다. 오컴의 면도날 관점에서 훌륭한 결과.
  • Behavioral 분석의 깊이: 단순 accuracy를 넘어 CoT 행동, cognitive behavior, skill embedding까지 분석해 왜 breadth가 필요한가를 mechanistic하게 설명.

한계와 의문점

  • 모델 스케일이 여전히 작다: 7~9B 파라미터 범위. 32B, 72B, 100B+ 모델에서도 같은 결론이 성립하는지 미확인. 저자들도 limitations에서 이를 인정.
  • Video, multi-turn 부재: 6개 카테고리는 여전히 정적 이미지 기반. Video reasoning이나 대화형 추론에서의 recipe 유효성은 미검증.
  • Behavioral 분석이 descriptive에 그침: STEM이 backtracking을 유도한다는 관찰은 확인되지만, backtracking이 실제로 accuracy를 얼마나 유발하는지 causal한 실험은 부재.
  • Taxonomy 검증 부족: 6개 카테고리 자체가 최적인지, 이보다 세분하거나 다른 축(예: perception vs reasoning)이 더 효과적일지 비교 없음.
  • Uniform mixing의 놀라운 우위: difficulty-weighted, length-weighted, size-weighted 모두 uniform보다 못한 것은 흥미롭지만, 왜 그런지에 대한 이론적 설명은 약함. FLAN 논문의 결과와 유사한 empirical한 관찰에 머문다.
  • LLM Judge 조작 위험의 잔존: 명시적 실패 조건으로 대응했지만 근본적으로 judge model이 Qwen3-32B라는 점에서 hackable. Judge와 policy가 같은 계열일 때 collusion 가능성이 우려된다.
  • GSPO vs GRPO 차이가 크지 않다: 54.7 vs 54.3 (Δ+0.4). Entropy 안정성 논거는 설득력 있지만, 결과적 성능에서 GSPO 필수인지는 모호. 알고리즘 개선보다 데이터 큐레이션이 훨씬 큰 driver임을 저자들도 인정.

실무 관점 트레이드오프

  • Compute 비용: 600K 샘플 × 8+ rollouts × GSPO는 상당한 GPU 리소스를 요구. Small team이 재현하려면 6개 카테고리 균등 sample을 축소하는 것이 자연스러운데, 어느 크기까지 compress해도 성능이 유지되는지 curve가 부재.
  • 답 필터 자동화의 신뢰성: Qwen3-235B로 answer normalization을 수행하는 파이프라인은 그 자체가 재현 비용이 큼. 더 작은 오픈 모델로 대체 가능한지 미확인.

Key Takeaways: 이 논문에서 가져갈 것

  • General visual reasoning은 optimizer 문제가 아닌 distribution 문제: RL 알고리즘을 튜닝하기보다 태스크 카테고리 균형과 답 타입별 reward routing에 투자하는 것이 훨씬 크게 기여한다.
  • Task-routed reward는 general VLM RL의 필수 요건: math_verify 단일 reward에 의존하면 개방형 능력이 붕괴한다. 답 포맷별 verifier 라이브러리 구축이 실무의 첫 단계.
  • Single-task RL은 위험한 선택: 자기 도메인 성능은 오르지만 non-target 카테고리에서 최대 −35점 붕괴. Production VLM에는 반드시 mixed-task RL을 적용.
  • Uniform mixing이 시작점: 복잡한 curriculum이나 hard-example mining보다 균등 분배가 강력한 baseline. 이를 넘어서기 어렵다.
  • Base 모델에 직접 RL 적용도 가능: Qwen3.5-9B-Base에 SFT/distill 없이 +12.9점 개선. warm start의 필수성에 대한 통념 재검토 계기.
  • LLM-as-judge reward hacking은 자기평가 문장 감지로 대응 가능: 실무에서 open-ended reward를 도입할 때 즉시 활용 가능한 기법.
  • CoT 행동은 카테고리별로 근본적으로 다르다: STEM=backtracking, Grounding=visual search, Captioning=mental imagery. 이는 domain-specific reasoning model이 fundamentally distinct behavioral regime을 갖는다는 강력한 증거.
