TL;DR

  • 문제: Vision-Language Model (VLM)이 대부분 autoregressive (AR) 디코딩에 의존하기 때문에, 배치 크기 1인 로봇/자율주행 같은 physical AI 환경에서 메모리 대역폭에 병목이 걸려 하드웨어 병렬성을 활용하지 못한다. Block-wise discrete diffusion은 텍스트에서 병렬 디코딩 대안으로 유망하나, VLM으로 확장하려면 연속적 시각 표현과 이산 텍스트를 동시에 다루면서 사전학습된 멀티모달 능력을 보존해야 하는 난제가 있다.
  • 해결: 사전학습된 AR VLM(Qwen2.5-VL-3B)을 단일 단계 multimodal fine-tuning으로 곧바로 block-diffusion VLM으로 변환하는 direct conversion 레시피를 제안. 여기에 (1) block-size annealing, (2) causal context attention, (3) auto-truncation attention mask, (4) vision-efficient concatenation, (5) self-speculative block decoding을 결합해 KV-cache와 호환되며 SGLang까지 통합해 production-grade 서빙까지 지원.
  • 왜 작동하는가: AR VLM은 이미 멀티모달 정렬을 마쳤기 때문에, text-only에서 시작해 재정렬을 다시 배우는 two-stage 경로보다 같은 예산으로 훨씬 효율적으로 diffusion으로 변환 가능. Causal attention을 clean stream에 유지하면 AR 손실과 diffusion 손실을 한 forward pass에서 함께 학습할 수 있고, 추론 시 AR 모드로 self-speculative verification까지 수행 가능.
  • 비유: 이미 두 언어(비전+텍스트)를 통역할 줄 아는 사람에게 "빠르게 통째로 말하는 법(diffusion)"을 가르치는 것 vs. 한 언어(텍스트)만 아는 사람에게 먼저 빠른 말투를 가르치고 나서 두 번째 언어까지 새로 가르치는 것 — 전자가 훨씬 빠르고 정확하다.

핵심 기여 (Key Contributions)

  1. Fast-dVLM 제안: KV-cache 호환 병렬 디코딩과 self-speculative decoding을 모두 지원하는 block-diffusion VLM으로, AR 대비 큰 폭의 추론 속도 향상을 달성하면서 경쟁력 있는 품질을 유지.
  2. AR-to-Diffusion 변환 전략 체계 비교: two-stage(먼저 텍스트만으로 LLM을 diffusion으로 변환 → 이후 멀티모달 fine-tuning)와 direct(전체 AR VLM을 한 단계로 변환) 경로를 동일 예산에서 controlled comparison해, ##direct 경로가 평균 정확도 73.3 vs. 60.2로 압도적으로 우수##함을 실증.
  3. 4가지 학습 레시피 컴포넌트: block-size annealing (curriculum), causal context attention, auto-truncation masking, vision-efficient concatenation — 각각 ablation으로 검증. Causal context 제거 시 -22.5%, annealing 제거 시 -4.4%, auto-truncation 제거 시 -3.7% 평균 하락.
  4. 11개 멀티모달 벤치마크에서 AR와 대등: MDM 디코딩 시 평균 73.3, speculative 시 74.0으로 AR baseline (74.0)과 동일. GQA/POPE/RealWorldQA에서는 AR을 능가.
  5. 시스템 통합으로 최대 6.18× 가속: SGLang 통합 + SmoothQuant W8A8 (FP8) 결합으로 MMMU-Pro-V에서 AR baseline 대비 6.18× 처리량 향상 (56.7 → 350.3 TPS).

배경 지식 (Background)

Autoregressive vs. Block Diffusion for Language

AR 언어 모델은 다음 토큰을 순차적으로 하나씩 예측한다:

$$P_\theta(\mathbf{x}) = \prod_i P_\theta(x_i \mid x_{직관적으로 말하면, 각 토큰의 조건부 확률을 왼쪽 문맥에만 의존해 계산하므로 병렬 처리가 어렵고 배치 1 상황에서 GPU 연산 자원이 놀게 된다.

Masked diffusion language model은 각 토큰을 확률 $t \in (0,1)$로 독립적으로 마스킹하고, 역방향 모델 $p_\theta(\mathbf{x}_0 \mid \mathbf{x}_t)$가 마스크된 토큰을 복원하도록 학습한다. Block-wise discrete diffusion은 시퀀스를 크기 $\hat{B}$의 블록으로 나눠, 블록 단위로는 autoregressive하고 블록 내부에서는 병렬로 denoising한다. 이 구조는 이미 완료된 블록의 KV cache를 다음 블록에서 재사용할 수 있어 실용적 가속을 가능케 한다.

Fast-dLLM v2 (Wu et al., 2025a)와의 관계

Fast-dVLM은 Fast-dLLM v2의 complementary masking과 dual-stream (noisy + clean) block attention 설계를 그대로 계승한다. 즉, 학습 시 응답 텍스트만 오염시킨 noisy stream $\mathbf{w}^t$와 원본 clean stream을 함께 concatenate해 하나의 시퀀스로 입력한다. 다만 Fast-dLLM v2는 clean-to-clean 부분에도 block-level bidirectional attention을 썼는데, Fast-dVLM은 이 부분을 token-level causal attention으로 바꿔 AR 능력을 보존한다 (self-speculative verification의 핵심 전제).

기존 Diffusion VLM들의 한계

LLaDA-V (You et al., 2025), LaViDa (Li et al., 2025b), MMaDA (Yang et al., 2025), Dimple (Yu et al., 2025) 등은 모두 full-sequence diffusion (블록 구조 없음)을 사용하기 때문에:

  • 이미 생성된 블록의 KV cache를 재사용할 수 없어 매 스텝 전체 시퀀스 recomputation 필요
  • Multi-turn dialogue에서 응답 경계를 다루는 turn-aware attention masking 부재
  • Speculative verification과의 통합 부재

기존 block-diffusion 계열 (Arriola et al., 2025a; Wu et al., 2025a; Gat et al., 2025)는 KV 캐싱을 지원하나 텍스트 전용에 국한되어 있어, 본 논문이 VLM 세팅으로 확장을 시도한다.

방법론 (Methodology)

3.1 4가지 VLM 특화 도전 과제

Fast-dLLM v2의 텍스트 전용 프레임워크를 VLM으로 확장할 때 4가지 문제가 발생한다:

  1. Conversion strategy: 사전학습된 AR VLM을 two-stage (text-first)로 변환할지, direct (한 번에)로 변환할지
  2. Multi-turn boundaries: 짧은 응답(예: 단일 선택지 문자)은 마지막 denoising block이 다음 turn의 prompt로 확장돼 미래 정보 누출 발생
  3. Training efficiency: Noisy-clean concatenation이 vision embedding을 두 stream에 중복 저장 → 메모리/연산 낭비
  4. Causal compatibility: Block-level context attention은 사전학습된 causal 구조를 파기해 self-speculative verification을 위한 AR 디코딩이 불가능

3.2 AR-to-Diffusion 변환 전략

Two-stage path: Stage 1에서 LLM backbone만 300K text-only 샘플에 대해 Fast-dLLM v2 레시피로 text-only diffusion fine-tuning; Stage 2에서 vision encoder + MLP projector를 붙여 전체 모델을 멀티모달 데이터로 fine-tuning (vision encoder도 unfrozen).

Direct path (권장): 완전한 AR VLM을 곧바로 single-stage multimodal fine-tuning으로 block-diffusion 모델로 변환. 사전학습된 멀티모달 정렬을 최대한 활용.

Two-stage: AR LLM (Qwen2.5-Instruct-3B) → [text-only diff FT] → Diffusion LLM → [+ViT + MLP, multimodal FT] → Fast-dVLM (Two-Stage) Direct: AR VLM (Qwen2.5-VL-3B) → [single-stage multimodal diff FT] → Fast-dVLM (Direct)

3.3 학습 세부사항

Dual-stream input과 attention mask

입력을 $\mathbf{x} = (\mathbf{v}, \mathbf{w})$ (vision embedding + text embedding)로 두고, 응답 토큰만 오염시킨 noisy stream $\mathbf{w}^t$을 clean stream과 concat해 $[\mathbf{w}^t; \mathbf{x}]$를 형성. Attention mask는 3가지 규칙을 강제한다:

  • $\mathcal{M}_{\text{N2N}}$ (block-diagonal, Noisy→Noisy): noisy 토큰이 자신의 블록 내에서만 양방향 attention → 병렬 denoising 가능
  • $\mathcal{M}_{\text{N2C}}$ (offset block causal, Noisy→Clean): noisy 토큰이 이전 블록의 clean context (vision 포함)에만 attend
  • $\mathcal{M}_{\text{C2C}}$ (token causal, Clean→Clean): ##clean stream에는 token-level causal attention을 유지 — Fast-dLLM v2의 block-level context attention 대비 AR 표현을 더 잘 보존하며 self-speculative verification 가능케 함##
[Figure 3 설명]: 블록 크기 $\hat{B}=2$ 예시. 색상별 attention 영역이 표시되며, noisy $\mathbf{w}^t_0, \mathbf{w}^t_1, \mathbf{w}^t_2$은 서로 자신의 블록 내에서만 파란색 block-diagonal 영역으로 상호작용하고, clean 스트림의 vision + text ($v, \mathbf{w}^0_0, \ldots$)로는 초록색 offset block-causal로 뒤로 접근한다. Clean 스트림 내부(붉은색)는 완전한 token-level lower-triangular causal mask.

Block-size annealing (curriculum)

후보 블록 크기 $S = \{2^1, 2^2, \ldots, B_d\}$ ($B_d = 32$)와 학습 진행률 $u \in [0,1]$에 대해, 활성 블록 크기를 다음과 같이 정한다:

$$\hat{B} = S[\min(\lfloor u \cdot |S| \rfloor, |S|-1)].$$

직관적으로 말하면, 학습 초기에는 작은 블록(=적은 마스킹 스팬)으로 fine-grained denoising을 익히고, 진행됨에 따라 큰 블록으로 노출시킨다. Ablation에서 이 커리큘럼 없이 곧바로 $B_d=32$로 학습하면 평균 -4.4%, MMMU-Pro-V에서는 -32.5%로 특히 long-form 생성에서 손실이 크다.

Auto-truncation attention mask

멀티턴 대화에서 응답 길이가 $\hat{B}$의 배수가 되지 않는 경우 (예: 응답이 단일 문자), 마지막 denoising 블록이 다음 턴의 prompt로 확장돼 $\mathcal{M}_{\text{N2N}}$이 미래 prompt 토큰을 attend하는 문제 발생. 해결: 각 응답의 마지막 블록을 응답 경계에서 자동으로 truncate. 이를 통해 cross-turn leakage 방지하면서 block-parallel denoising은 유지. Ablation: 제거 시 평균 -3.7%, MMMU -14.4%.

Vision-efficient concatenation

Vision embedding은 절대 오염되지 않으므로 noisy stream과 clean stream 양쪽에서 동일하다. 따라서 clean stream에만 vision을 포함시키고, noisy stream에는 text 위치만 두며, noisy에서 vision으로의 attention은 $\mathcal{M}_{\text{N2C}}$를 통해 처리. Qwen2.5-VL-3B (context 2048, H100)에서 이 lossless 최적화가 peak memory 15.0% 감소, 학습 시간 14.2% 단축.

Training objective

$W$가 LM head, $\mathbf{H}^{(t)}, \mathbf{H}^{(0)}$이 각각 noisy/clean stream hidden states, $\mathbf{y}$가 응답 라벨일 때:

$$\mathcal{L} = \alpha\, \text{CE}\bigl(W \mathbf{H}^{(t)}, \mathbf{y}\bigr) + \beta\, \text{CE}\bigl(W \mathbf{H}^{(0)}, \mathbf{y}\bigr), \quad \alpha=\beta=0.5.$$

직관적으로 말하면, ##diffusion branch는 병렬 denoising을 학습하고 causal branch는 AR 생성 능력을 보존해, 하나의 모델로 두 모드를 모두 지원할 수 있게 한다.##

3.4 추론 (Inference)

Causal context decoding

각 블록은 캐시된 causal context에서 첫 토큰을 AR 단일 스텝으로 생성하고, 남은 $\hat{B}-1$ 위치를 [MASK]로 채워 반복적으로 denoising. 이는 학습 시 causal attention 패턴과 자연스럽게 정렬된다.

Self-speculative block decoding

Diffusion 모드로 $\hat{B}-1$개 토큰을 한 번의 forward pass로 draft한 뒤, 같은 모델의 causal 모드로 autoregressively 검증하고, 가장 긴 일치 prefix를 accept한 뒤 KV cache를 그에 맞게 자름. 두 가지 변형:

  • Linear scheme: 블록당 정확히 2 forward pass (draft + verify)
  • Quadratic scheme: 검증과 다음 블록 제안을 단일 forward pass로 fuse — $O(\hat{B}^2)$ 입력 토큰. 이론적으로 NFE 우수하나 비표준 attention mask로 커널 최적화가 어려워 wall-clock TPS는 linear보다 낮음
[Prefill causal attention] → 첫 토큰 x_L+1 ← argmax h_L while not done: d = [x_n, MASK, MASK, ..., MASK] # B 토큰 [Draft (bidirectional)]: h_hat ← Forward(d, no cache) x_hat_i = argmax h_hat_{i-1} for i=1..B # shift-by-one 예측 [Verify (causal)]: h_v, KV ← Forward(d, update cache) a_i = argmax h_v_i for i=0..B-1 k = min {j: a_j ≠ d_{j+1}}; k ← k+1 # 첫 mismatch Append a_{0..k-1}; n ← n+k KV ← Crop(KV, n-1)

System integration

SGLang scheduler를 확장해 bidirectional draft attention과 causal verify attention이 동일한 paged KV cache를 공유. 이를 통해 SGLang의 최적화된 커널과 CUDA graph의 혜택을 받음. 추가로 SmoothQuant W8A8 (FP8) 양자화 적용.

패턴 분석:

  • Causal context가 압도적으로 중요 (-22.5% 평균). Block-level bidirectional attention으로 대체하면 사전학습된 AR sequential reasoning 능력이 파괴되며, 특히 reasoning-heavy MMMU-Pro-V(-58.9%)와 SEEDBench2+(-39.5%)에서 치명적. AR loss와의 co-training도 여기에 의존.
  • Annealing은 long-form에 중요: 평균 -4.4%지만 MMMU-Pro-V에서만 -32.5%. 큰 corruption span을 다루려면 작은 블록부터 점진적 노출 필요.
  • Auto-truncation은 MMMU에서 결정적: 평균 -3.7%, MMMU -14.4%. Cross-turn 정보 누출을 방지해 training/inference 신뢰성 확보.

이 실험이 뒷받침하는 주장: 4가지 컴포넌트가 서로 다른 실패 모드를 방어함 — causal context는 reasoning 보존, annealing은 large-span denoising 학습, auto-truncation은 multi-turn 무결성. 어느 하나도 생략 불가.

4.5 Inference Acceleration

Decoding threshold $\tau$의 영향: MDM 디코딩에서 신뢰도 임계값이 병렬성을 조절. $\tau=1.0$ (매 스텝 1 토큰): 정확도 21.6, $\tau=0.9$: tokens/step 1.95×에 정확도 21.4로 near-lossless, $\tau=0.4$: tokens/step 2.90 최대 병렬성이지만 정확도 18.5로 급락. ##$\tau=0.9$가 quality-speed 균형점.##

Speculative decoding 비교 (linear vs. quadratic):

[Figure 6 설명]: 블록 크기 4/8/16/32에 걸쳐, Tokens/NFE는 block size에 따라 단조 증가 (linear 1.78→2.74, quadratic 2.99→4.00). 그러나 wall-clock TPS는 linear가 블록 16 (112.7 TPS)에서 peak 후 32에서 소폭 하락, quadratic은 모든 블록에서 linear보다 낮음. 이유: quadratic은 $\hat{B}(\hat{B}+1)$ 입력 토큰과 비표준 attention mask 때문에 현재 커널 최적화가 어려움.

비판적 분석 (Critical Analysis)

강점

  • Controlled AR-to-Diffusion 비교의 명료함: 동일 데이터/예산에서 direct vs. two-stage를 정면 비교해 direct가 우세하다는 결론에 강한 실증적 근거 제공. 이는 향후 diffusion VLM 연구의 default recipe를 확정하는 실용적 가치가 큼.
  • Causal context ablation의 극적 결과: -22.5% 평균 하락은 "block-level bidirectional이 무조건 낫다"는 기존 diffusion 관행에 대한 명확한 반례. AR loss와의 co-training을 위해서라도 clean stream causal이 필수임을 강조.
  • System-level 통합의 완결성: 학습 알고리즘 수준에 그치지 않고 SGLang scheduler 확장 + FP8까지 다뤄, 논문 결과가 곧바로 production에 옮겨질 수 있음. 대다수 diffusion LM 논문이 커널/서빙 이슈를 회피하는 것과 대비.
  • Vision-efficient concatenation: 15% peak memory + 14.2% 학습 시간 절감이라는 명확한 실용 gain. Vision과 text의 diffusion 대칭성 차이를 정확히 활용.

약점 및 한계

  • Long-form reasoning 격차 (MMMU-Pro-V -1.7 ~ -4.9): Block-wise parallel denoising의 구조적 한계. 저자는 데이터/annealing 확장으로 좁힐 수 있다고 시사하지만 실증되지 않음. Physical AI의 CoT-heavy 상황에서는 여전히 quality trade-off 존재.
  • 단일 백본/스케일 검증: Qwen2.5-VL-3B에만 적용. 7B/13B급 혹은 다른 아키텍처(예: LLaVA-계열, InternVL)에서 direct path의 우세가 유지되는지 확인 필요.
  • Two-stage 초기화 선택 편향 가능성: Two-stage가 Qwen2.5-Instruct-3B (LLM)에서 시작해 새 ViT를 붙이는데, 이 조합이 최선의 two-stage recipe인지는 열린 질문. LLaDA/Dream 등 이미 정제된 diffusion LLM 위에 ViT를 붙이는 실험은 없음.
  • MMBench/MMMU 소폭 하락: MDM 디코딩 시 -2.7 / -2.7 (Table 1). Speculative가 이를 완전히 복구하지 못함 (MMBench 74.3 vs. AR 76.9). 즉 "lossless"는 평균 기준이지 모든 벤치가 아님.
  • Quadratic speculative의 실용성 부재: 이론적 NFE 우수함에도 커널 미최적화로 wall-clock에서 linear에 밀림 — 앞으로 커널 개발이 필요한 오픈 이슈로 남음.
  • 재현성: 2M 학습 샘플 조합이 상세히 열거되어 있으나, 정확한 sampling ratio나 데이터 준비 스크립트는 부재. GitHub/Project Page 링크 존재 (검증 필요).

확장 가능성

  • Direct conversion 레시피는 다른 modality (audio-language, video-language)에도 직접 적용 가능성. Vision-efficient concatenation의 논리 (오염되지 않는 modality는 clean stream만 유지)는 일반화됨.
  • Self-speculative의 draft-verify 통합 KV cache 설계는 AR과 diffusion 모드가 공존하는 모든 hybrid model (예: Nemotron-Labs-Diffusion 같은 tri-mode 계열)에 재사용 가능.
  • Long-form 격차 축소를 위해, 저자가 시사한 annealing schedule 확장 외에도 RL/DPO 계열의 diffusion 사후 학습 (d1, MMaDA)과의 결합이 유망.

Key Takeaways

  • ##사전학습된 AR VLM은 diffusion VLM으로 변환할 때 "이미 습득한 멀티모달 정렬"이라는 자산이 되며, text-first two-stage보다 direct single-stage가 same-budget에서 압도적으로 유리 (73.3 vs. 60.2)##. 이는 향후 다른 다중 모달 diffusion 모델 설계의 default heuristic이 될 만한 발견.
  • ##Block-diffusion VLM에서 clean stream의 token-level causal attention은 협상 불가능한 요소##. Reasoning 능력 보존과 self-speculative verification 모두 여기에 의존. -22.5% 평균 하락은 이 설계의 필수성을 강력하게 뒷받침.
  • Block-size annealing / auto-truncation / vision-efficient concatenation은 각각 다른 실패 모드를 방어하는 독립적 컴포넌트로, 하나라도 빠지면 무너지는 취약한 시너지가 아닌 상호보완적 설계.
  • Speculative decoding + SGLang + FP8을 결합한 6.18× 가속은 커널/서빙 통합이 diffusion LM 실용화의 최대 배수 기여자임을 시사. 알고리즘만 개선하는 것보다 시스템까지 통합할 때 실제 wall-clock 이득이 극대화됨.
  • Physical AI (배치 1, 엣지 디바이스, 로봇/자율주행)에서 AR의 memory-bandwidth 병목이 얼마나 심각한지, 그리고 block-diffusion이 얼마나 자연스러운 해결책인지를 명확히 프레이밍. 응용 방향에 실질적 impact.
