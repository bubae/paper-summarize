Discrete Diffusion의 원리 (Figure 3 재현)

2-token canvas 예시: "blue moon" (t=1.0, noise) → "dark cloud" → "bright horizon" → "red sunset" (t=0.0, data). 시간 역행하며 uniform noise에서 유효한 데이터 mode로 확률 질량이 이동한다.

Figure 3 재현: 개별 시퀀스가 backward-time으로 uniform noise → 데이터 mode로 이동하는 궤적. 두 canvas 위치가 독립적으로 병렬 진화하지만 학습된 posterior가 그들을 조율.

Multinomial vs Masked Diffusion

DiffusionGemma는 multinomial(uniform) diffusion을 채택. 각 토큰이 어휘 전체에서 uniform하게 선택된 랜덤 토큰으로 대체된다. Masked diffusion과 달리 ##앞 step에서 잘못 sample된 토큰도 이후 step에서 재수정 가능##. Previous canvas의 토큰은 freeze되지만, 현재 canvas 내에서는 flexible.

Block-AR 생성 파이프라인 (Figure 4 재현)

Figure 4 재현: (1) causal encoder가 프롬프트를 KV cache로 인코딩 → (2) bidirectional decoder가 canvas를 반복 denoise (self-conditioning으로 이전 예측 재사용) → (3) 완성 canvas를 KV cache에 append하고 다음 canvas 시작.

왜 이 구조가 우아한가

기존 BART/T5는 bidirectional encoder + causal decoder. DiffusionGemma는 이를 역전: causal encoder + bidirectional decoder. 이 배치의 장점은 encoder KV cache가 append-only라는 점 — 새 canvas가 완성될 때마다 전체 컨텍스트를 재계산할 필요 없이 마지막 canvas만 encode해 append. Long context에서도 O(1) 증분 비용.

Task complexity에 따라 denoising step 수가 동적으로 조정된다.

Figure 5 재현: adaptive stopping이 task complexity에 dynamic 적응. 최대 N=48 예산 중 실제 사용은 평균 12 step (4× 감소).

SD·RL 학습 다이나믹스 (Figure 8 재현)

이 논문의 핵심 아이디어: reward와 sampler compression을 동시 최적화. 자연스러운 curriculum이 emerge한다.

Figure 8 재현: SD·RL 학습 중 reward는 0.27 → 0.38로 상승, effective denoising steps는 50 → 20으로 감소. Quality와 Speed가 함께 개선.

1. Reward Maximization

Helpfulness, math, code, IF 등 표준 RL objective. Online teacher가 매 step 생성한 trajectory 위에서 reward 계산.

2. Sampler Distillation

고품질 output을 few-step regime으로 압축. Predictive entropy 최소화로 adaptive stopping이 조기 발동.

3. Emergent Curriculum

Entropy ↓ → adaptive stopping 조기화 → teacher trajectory ↓ → 학습 분포가 자연스럽게 짧은 궤적으로 이동. 자기 강화 루프.

GPU 시간 분해: 왜 diffusion이 3.2× 만 느린가 (Figure 11 재현)

Figure 11 재현: 256 tokens 병렬 처리에 3.2× 만 더 걸림. TPF ~20이므로 실질 speedup ~6.3×.

왜 3.2× 만 느린가

MoE ×4.3: AR은 8 experts activate, diffusion은 canvas당 평균 84 experts. 그러나 memory bandwidth 병목이 완화되면서 이 오버헤드가 상쇄됨. Sampling ×5.5: 256-token softmax + self-conditioning FFW (V=262k). PyTorch primitives라 kernel 최적화 여지 존재. Attention ×4.1: FlashAttention-4 최적화됨.

Diffusion만의 능력: Bidirectional Self-Correction (Section 9.1)

AR의 한계

다단계 산술 문제 "(어떤 계산) = ?" 에서 AR은 답을 중간 계산 전에 커밋해야 함. 잘못된 예측(예: −1)을 이후 계산으로 수정할 수 없음.

Answer: −1 (커밋됨) →
3 + 4 × 2 = ...
[수정 불가능]

Diffusion의 우위

Canvas 전체가 병렬 진화. 답과 reasoning이 공진화하며 초기 잘못된 −1이 iteration을 거쳐 −25로 coarse-correct 될 수 있음.

t=1.0: Answer: −1, 3+..
t=0.5: Answer: −12, 3+4×..
t=0.0: Answer: −25 ✓

Sudoku 실험: Non-AR task의 shining case

Base DiffusionGemma는 Sudoku 정답률 0.00% (특수 훈련 없음). LoRA rank 8만으로 fine-tune 시 84.40%. 게다가 average denoising steps가 40.65 → 10.72로 감소 — 확신이 높아진 만큼 조기 종료. Sudoku는 좌→우 순서가 무의미하고 전역 constraint 만족이 필요한 문제라 bidirectional refinement가 이상적으로 정합.

한계점

Absolute Quality Gap

TD mode는 AR mode 대비 여전히 3~15점 뒤짐. AIME 2026: 69.1 vs 84.2, LCB-v6: 69.1 vs 71.4. 속도를 위해 상당한 지능을 희생.

Batch Scaling 취약

c=32+에서 AR (MTP)이 역전. 대규모 chatbot 서비스에는 여전히 AR이 유리. Diffusion 우위 영역이 low-batch에 국한.

Thinking-Knowledge 상충

MMLU-Pro에서 thinking mode가 오히려 −11.7점. Diffusion 특유 무엇이 knowledge recall과 상충하는가는 분석 부족.

MoE 재사용의 우연성

Canvas당 84 experts activate. Dense 모델이었다면 결과가 어땠을지 미확인. Sparse MoE와 diffusion의 궁합이 필수 조건인지 불명.

Kernel 최적화 여지

Sampling(3.06ms, 24%)이 PyTorch primitives라 kernel 미최적화. Custom CUDA로 상당한 speedup 여지.

한 줄 결론

"AR 모델을 diffusion 모델로 재활용할 수 있고, SD·RL 통합 objective는 quality와 latency를 동시에 개선한다. Text diffusion의 실전 가능성을 입증한 첫 오픈 모델."
