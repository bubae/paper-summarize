TL;DR

  • 문제: Text/Vision/Audio 각 modality specialist teacher들을 하나의 omni-modal student로 통합하려 할 때, (1) 여러 teacher가 shared backbone을 서로 다른 방향으로 밀어 충돌이 생기고, (2) OPD의 symmetric 목적함수가 student가 이미 teacher를 넘어선 부분까지 뒤로 잡아당기는 "teacher ceiling" 문제가 발생한다.
  • 해결: ##OPOD (On-Policy Omni Distillation)##. 세 가지 컴포넌트로 해결한다 — (1) One-Sided Teacher Guidance: teacher가 student보다 앞선 토큰에만 constraint 적용 (ReLU로 negative margin 제거), (2) Adaptive Modality Control: modality별 constraint budget과 dual weight $\beta_m$을 별도로 유지하여 modality마다 다른 속도로 훈련, (3) Verification Reward: 라우팅된 teacher가 answer confidence(정답 게이팅)와 reasoning gain(gain 게이팅 없이)을 별도로 평가.
  • 왜 작동하는가: One-sided는 학생이 이미 넘어선 부분까지 끌어당기지 않으므로 teacher ceiling을 우회한다. Modality-adaptive weight는 text/audio/image의 discrepancy 자연 스케일이 12.7배 차이나는 것을 흡수해 shared weight의 broad tradeoff를 방지한다. Verification reward는 outcome sparsity를 완화한다.
  • 비유: 세 명의 서로 다른 스포츠 코치가 한 선수를 가르치는 상황. 기존 방식은 세 코치 모두 매 순간 선수를 "잡아당기고" 서로 방향이 어긋난다. OPOD는 각 종목의 코치는 자기 종목 데이터에서만 조언하되, 선수가 코치보다 잘하는 순간엔 물러나고, 코치별 강도(β)를 균형 잡히게 자동 조절한다.

핵심 기여 (Key Contributions)

  1. 문제 규명: Modality-specialist teacher를 하나의 shared backbone에 OPD로 통합할 때 발생하는 두 가지 challenge — conflicting guidance와 teacher ceiling을 정량적으로 분석 (Figure 1a-c).
  2. One-Sided Guidance: 표준 OPD의 log-ratio를 ReLU로 잘라 teacher가 앞설 때만 constraint를 적용. 이로써 student가 이미 강한 token에서는 "backward pull"이 사라진다.
  3. Adaptive Modality Control: 각 modality $m$에 대해 warm-up에서 average constraint $\bar{c}_m$을 계산해 target budget $\epsilon_m$을 개별 calibration. Dual variable $\beta_m$이 constraint gap $\bar{c}_m - \epsilon_m$을 따라 자동 조정.
  4. Verification Reward: 라우팅된 teacher를 verifier로 재활용. Answer confidence는 correctness로 게이팅, reasoning gain은 gain을 clip만 하고 correctness 게이팅 없이 사용 → 오답에서도 학습 신호 확보.
  5. 실증: 12개 벤치마크(text 5개, vision 4개, audio 2개, omni 1개)에서 30B-A3B / 7B / 3B 세 스케일 모두 최고 평균 달성. ##Qwen3-Omni-30B-A3B 기준 70.8## 로 baseline 대비 +3.8, 강한 비교군 대비 +2.1 개선.

배경 (Background)

Omni-modal 모델과 post-training의 어려움

Omni-modal LLM은 text, image, audio를 shared backbone에서 처리한다. 그러나 shared backbone은 한 modality의 개선이 다른 modality의 성능을 그대로 유지해준다는 보장이 없다 — 각 modality가 요구하는 표현 특성이 다르기 때문이다. 저자들이 통제된 실험(same base model, GRPO만 다르게 적용)에서 관찰한 바에 따르면, text/image/audio 각각의 specialist는 자기 modality에서 강력해지지만 pooled data로 훈련한 mixed model은 이 강점들을 "합집합"으로 모으지 못한다 (Figure 1a의 radar chart).

더구나 각 specialist가 base로부터 이동한 parameter direction을 비교하면 modality 쌍 사이의 방향 충돌(direction conflict)이 빈번하다 (Figure 1b). 즉 하나의 shared weight가 세 방향의 gradient를 동시에 만족시키는 것은 근본적으로 어렵다.

On-Policy Distillation (OPD)

OPD는 최근 model post-training의 표준 도구가 되었다. Sequence-level distillation이 pre-collected teacher trajectory를 imitation하는 반면, OPD는 student가 sampling한 rollout에 대해 teacher와 student의 next-token distribution을 각 prefix에서 비교한다.

Student policy $\pi_\theta$와 teacher policy $\pi_T$에 대해 OPD reward는 다음과 같다:

$$r^{\text{opd}}_{i,t} = \log \pi_T(y_{i,t} \mid x_i, y_{i,

이 log-ratio는 student rollout에 대한 reverse-KL의 dense token-level reward에 대응한다. 직관적으로 말하면, teacher와 student의 확률차가 각 위치에서 "얼마나 학생이 이 토큰을 더 잘/못 예측하는가"의 dense signal이다. 이는 outcome reward만 있는 sparse RL과 달리 매 토큰에서 감독을 준다.

Omni 상황에서의 두 가지 문제

이 OPD를 여러 modality teacher로 확장하면:

  • Conflicting guidance: 각 teacher는 자기 modality를 잘 다루는 방향으로 backbone을 밀지만 방향이 어긋난다. 하나의 공유된 guidance weight로는 세 신호를 독립적으로 조절하기 어렵다.
  • Teacher ceiling: 표준 OPD의 log-ratio는 대칭적이다. Student가 teacher보다 이미 잘하는 token에서도 mismatch를 줄이려 하므로 student를 뒤로 잡아당길 수 있다. 즉 teacher 수준이 student의 상한선이 된다.

기존 확장(Ma et al. 2026, Yin et al. 2026 등)은 multi-teacher OPD를 routing/arbitration으로 다루지만, 위 두 문제를 동시에 해결하지 않는다.

방법: OPOD

3.1 Preliminary와 표기

Prompt를 $(x_i, m_i)$로 표기하고 $m_i \in \{\text{text}, \text{audio}, \text{image}\}$가 modality label. 각 modality마다 미리 GRPO로 훈련된 specialist teacher $\pi_T^{m_i}$가 존재한다. 매 iteration에서 student가 rollout $y_i = (y_{i,1}, \dots, y_{i,T_i})$를 $\pi_\theta$에서 뽑고, 이 rollout은 $m_i$에 따라 routing된 teacher에게 평가된다.

3.3 One-Sided Teacher Guidance

Routed teacher-student margin을 다음과 같이 정의:

$$c_{i,t} = \text{ReLU}(r^{\text{opd}}_{i,t}) \tag{2}$$

즉 teacher가 student보다 앞선 토큰(margin > 0)에서만 constraint가 살아있다. Student가 이미 이 토큰을 잘 맞추면 margin=0이 되어 teacher가 뒤로 잡아당기지 않는다.

Rollout-level average는:

$$c_i = \frac{1}{T_i}\sum_{t=1}^{T_i} c_{i,t}$$

직관: 학생이 이미 잘하는 부분은 자유롭게 두고, 아직 약한 부분에서만 선생님의 감독을 유지한다. 표준 OPD의 backward pull을 제거하면서도 학습 자체는 계속된다.

3.4 Adaptive Modality Control

Modality $m$의 mini-batch subset $\mathcal{B}_m = \{i \in \mathcal{B} : m_i = m\}$과 modality-average constraint:

$$\bar{c}_m = \frac{1}{|\mathcal{B}_m|}\sum_{i \in \mathcal{B}_m} c_i$$

각 modality에 target budget $\epsilon_m > 0$이 설정되어 있고 (아래 warm-up으로 자동 결정), dual weight $\beta_m$의 update rule은:

$$\beta_m \leftarrow \text{clip}(\beta_m + \eta(\bar{c}_m - \epsilon_m), \beta_{\min}, \beta_{\max}) \tag{3}$$

이때 $\eta > 0$은 dual step size, $0 \le \beta_{\min} < \beta_{\max}$. 이 update는 $|\mathcal{B}_m| > 0$일 때만 적용된다.

직관: constraint gap $\bar{c}_m - \epsilon_m > 0$이면 그 modality는 예산을 초과했다는 뜻이므로 weight 증가로 pressure 강화. 이미 gap이 작으면 weight 감소.

Routed teacher constraint loss:

$$\mathcal{L}_{\text{tc}} = \frac{1}{|\mathcal{B}|}\sum_{i \in \mathcal{B}} \beta_{m_i} c_i$$

Budget calibration: $\epsilon_m$은 10-step warm-up 동안 관측된 mean warm-up constraint에서 결정하고, 이후 고정. 하한 $\epsilon_{\min}$으로 too-small budget을 방지. 실험에서 Qwen3-Omni-30B의 자동 calibration 결과는 $\epsilon_{\text{text}}=0.020$, $\epsilon_{\text{image}}=0.191$, $\epsilon_{\text{audio}}=0.254$로 12.7배 spread. 즉 modality마다 자연 스케일이 크게 다르므로 shared weight는 부적절하다.

3.5 Verification Reward

같은 modality teacher를 verifier로 재활용한다. 두 개의 signal:

(a) Answer confidence: Final answer position $S_i$에서 teacher가 gold answer $a_i^\star$에 얼마나 확률을 배분하는가:

$$A_i = \frac{1}{|S_i|}\sum_{t \in S_i} \log \pi_T^{m_i}(y_{i,t} \mid x_i, y_{i,

Correctness 게이팅:

$$\tilde{A}_i = \mathbf{1}[a_i = a_i^\star] \cdot \text{clip}(A_i, -C, 0)$$

즉 학생이 정답을 낸 rollout에서만 answer confidence를 신호로 삼는다.

(b) Reasoning gain: Reasoning trace $z_i$가 teacher가 gold answer를 예측하는 데 도움이 되는가:

$$B_i = \log \pi_T^{m_i}(a_i^\star \mid x_i, z_i) - \log \pi_T^{m_i}(a_i^\star \mid x_i)$$

Clip: $\tilde{B}_i = \text{clip}(B_i, -C, C)$.

중요: reasoning gain은 correctness 게이팅을 하지 않는다. Reasoning이 좋아 teacher가 정답 쪽으로 이동했다면 최종 정답이 틀렸어도 학습 신호가 남는다. 이는 어려운 sample에서 특히 값어치가 있다.

Process reward:

$$r_i^{\text{proc}} = w_A \tilde{A}_i + w_B \tilde{B}_i \tag{4}$$

기본값 $w_A = w_B = 0.2$, $C = 2.0$.

3.6 Training Objective

Task reward와 process reward의 합:

$$r_i = r_i^{\text{task}} + r_i^{\text{proc}}$$

Rollout group $\mathcal{G}_i$의 mean $\mu_i$, std $\sigma_i$에 대해 group-normalized advantage:

$$\hat{R}_i = \frac{r_i - \mu_i}{\sigma_i + \delta}$$

Policy loss:

$$\mathcal{L}_{\text{rl}} = -\frac{1}{|\mathcal{B}|}\sum_{i \in \mathcal{B}} \hat{R}_i \frac{1}{T_i}\sum_{t=1}^{T_i}\log \pi_\theta(y_{i,t} \mid x_i, y_{i,

Reference KL regularizer (rollout-averaged):

$$\mathcal{L}_{\text{ref}} = \frac{1}{|\mathcal{B}|}\sum_i \frac{1}{T_i}\sum_{t=1}^{T_i} D_{\text{KL}}(\pi_\theta(\cdot \mid h_{i,t}) \| \pi_{\text{ref}}(\cdot \mid h_{i,t}))$$

여기서 $h_{i,t} = (x_i, y_{i,

최종 objective:

$$\mathcal{L} = \mathcal{L}_{\text{rl}} + \mathcal{L}_{\text{tc}} + \alpha \mathcal{L}_{\text{ref}} \tag{5}$$

세 항은 동일한 on-policy batch로 계산. Task+verification reward가 rollout-level advantage를 만들고, $\mathcal{L}_{\text{tc}}$가 token-level guidance를 (teacher가 앞선 곳에만) 준다. Gradient는 shared student만 업데이트 — routed teacher와 reference는 고정.

4.1 실험 세팅

  • Student backbone: 주 실험은 Qwen3-Omni-30B-A3B-Instruct. 추가로 dense Qwen2.5-Omni 7B/3B에 대해서도 검증.
  • Teacher 구성: 같은 base에서 각 modality data로 GRPO를 개별 적용한 세 명의 specialist.
  • 학습 데이터: text/image/audio reasoning 및 multimodal QA를 다루는 modality-balanced prompt set (공개 데이터). 12개 벤치마크와의 exact + normalized string overlap을 제거하여 contamination 배제.
  • 비교 대상: base model / pooled GRPO / native OPD (Agarwal et al., Gu et al.) / ExOPD (reward extrapolation, Yang et al. 2026) / 세 modality specialist 자체.
  • 벤치마크 (12개):
    • Text: AIME25, AIME26, HotpotQA, MMLU-Pro, GPQA
    • Vision: MMMU, MathVista, ChartQA, A-OKVQA
    • Audio: MMAU, AVQA
    • Omni: OmniBench
  • 하드웨어/하이퍼파라미터: 32 × NVIDIA H20. Student 16 GPU + 나머지 GPU에 teacher server 호스팅. Prompt당 8 sample, rollout batch 16, global batch 64. Max prompt/response length 각 8192. Verification reward $w_A = w_B = 0.2$, $C = 2.0$. Dual controller warm-up 10-step, $\epsilon_{\min} = 0.02$. 모든 baseline이 같은 backbone/data/batch/seed 사용.

4.4 Adaptive Modality Control의 동역학 (Figure 4)

Calibration ($\epsilon_m$): 10-step warm-up 후 frozen 값 $\epsilon_{\text{text}} = 0.020$, $\epsilon_{\text{image}} = 0.191$, $\epsilon_{\text{audio}} = 0.254$. 12.7배 range → teacher-student discrepancy의 자연 스케일이 modality별로 크게 다름을 시사. Modality의 "난이도 순위"가 아닌 calibrated constraint gap의 스케일이다.

Constraint gap trajectory: 5-step moving average $\bar{c}_m - \epsilon_m$을 훈련 80 step에 걸쳐 관찰. Audio는 지속적으로 target 아래에 머무름 (예산 내), text는 점진적으로 target 아래로 내려감, image는 target 근처에 오래 머무름.

Control weight $\beta_m$ 도달 시점: 모두 약 0.6에서 시작. $\beta_{\min} = 0.1$에 처음 도달하는 step은 audio 24, text 54, image 80. 즉 audio는 빨리 예산에 진입해 controller가 pressure를 풀고, image는 훨씬 오래 boundary에 머물러 guidance가 지속. ##Weight schedule은 사전 지식이 아닌 관측된 constraint gap에서 데이터 주도적으로 자동 결정된다##.

비판적 분석 (Critical Analysis)

강점

  • Diagnostic가 명확함: Figure 1a-c의 세 그림은 문제를 실증적으로 설득한다 (specialist strengths, direction conflict, broad gain). 이 진단이 setup의 정당화 역할을 완결한다.
  • Modality budget의 데이터 주도적 결정: $\epsilon_m$을 수동 튜닝이 아닌 warm-up에서 자동으로 결정한 점은 실용적. 12.7배 스케일 차이가 실증적으로 관찰되어 shared weight의 부적절함을 강하게 뒷받침.
  • Reasoning gain의 asymmetric 게이팅: Answer confidence는 correctness로 게이팅, reasoning gain은 게이팅 없이 clip만 사용. 오답 rollout에서도 학습 신호를 살릴 수 있어 sparsity를 줄인다. AVQA/OmniBench에서 특히 유효.
  • Ablation의 breadth: 60개 비교 중 59개에서 full이 우위 — 광범위한 pattern임을 통계적으로 뒷받침.

약점 및 의문점

  • 단일 seed: "single run per configuration with the same random seed" (§4.1). Small-scale ablation은 seed 다중 실행 표준편차가 없어 point difference의 통계적 유의성이 불분명하다. Δ가 1점 대인 항목(reasoning gain 제거)은 특히.
  • $w_A = w_B = 0.2$의 sensitivity 부재: Verification reward의 강도 튜닝에 대한 sweep이 논문에 없다. Reasoning gain vs answer confidence의 balance가 modality 조합에 어떻게 의존하는지는 open.
  • $\beta_{\min}$의 역할: $\beta_m$이 0.1에 언제 도달하는지가 modality간 큰 차이를 보이는데, $\beta_{\min}$이 없으면 어떻게 되는가? $\beta_m = 0$까지 허용하면 modality guidance가 사라지는 실험이 필요.
  • Teacher pretraining 비용: 세 modality specialist를 GRPO로 미리 훈련하는 비용은 method cost에서 제외되어 있다. Compute-fair 비교는 (teacher training + distillation) vs (pooled GRPO)로 이뤄져야 한다.
  • Reference KL의 스케일: $\alpha$가 방법의 안정성에 미치는 영향에 대한 ablation이 없다. On-policy drift 방지의 필요성을 강조하지만 정량적 증거는 부족.
  • Modality가 3개인 세팅 특유의 결과일 수 있음: Video, 3D 등 추가 modality가 붙으면 conflict가 3-way를 넘어 4-way, 5-way로 확장된다. Dual variable update의 안정성과 calibration의 확장성은 실증되지 않음.
  • Verification의 answer extraction 가정: Final answer position $S_i$가 정확히 식별된다고 가정한다. Long-form reasoning trace에서 answer parsing이 실패하면 answer confidence 신호가 왜곡됨.

Key Takeaways

  • Multi-teacher OPD에서 "backward pull"을 제거하라: ReLU로 log-ratio를 한 방향으로만 자르는 간단한 변형만으로도 teacher ceiling을 우회할 수 있다. 다른 distillation setup(단일 teacher/task도 가능)에도 훈련시에 즉시 적용 가능한 아이디어.
  • Modality-specific dual weight는 필수: Text/image/audio의 자연 스케일 차이(12.7배)는 shared weight로 감당 불가. Multi-domain RL/distillation에서 hyperparameter를 domain별로 분리해야 하는 강한 실증적 근거.
  • Reward decomposition의 gating asymmetry: Correctness에 의존하는 신호(answer confidence)와 그렇지 않은 신호(reasoning gain)를 명시적으로 분리하는 것은 sparse reward 환경에 일반적으로 유효한 recipe. Reasoning-heavy 도메인(수학, 논리)에서 자체 응용 가치가 있다.
  • Deploy-time 부담 없음: 훈련 시엔 teacher server를 별도로 운영해야 하지만 (16 GPU + teacher servers) 배포 시 teacher는 모두 폐기 — inference latency와 memory에는 영향 없음.
  • 범용성 시사: MoE(30B-A3B), dense(7B, 3B) 모두에서 gain 유지. Method가 특정 model class에 의존하지 않는다.
