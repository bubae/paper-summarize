TL;DR

  • 문제: AR (autoregressive) LLM은 batch size=1 서빙에서 메모리 대역폭에 병목이 걸려 지연시간(latency)이 근본적으로 나쁘다. Speculative decoding으로 3~6 tokens/forward-pass(TPF)까지 짜낼 수 있지만 이것도 sequential drafter가 병목. Text diffusion 모델들은 폐쇄적(Mercury 2, Gemini Diffusion)이거나 오픈이어도 지능·속도 어느 한쪽이 부족했다.
  • 해결: Gemma 4 26B A4B MoE 모델을 10% 미만의 원 학습 토큰 예산으로 2단계 파인튜닝(SFT → SD·RL)해 discrete diffusion 모델로 변환. 256 토큰 블록을 ~12 forward pass에 병렬 refinement.
  • 왜 작동하는가: (1) AR weights를 재사용해 학습 비용을 획기적으로 절감. (2) Block-AR 구조: causal encoder(KV cache)로 컨텍스트 처리 + bidirectional decoder로 canvas denoising. (3) Sampler distillation과 RL을 동시에 학습(SD·RL)하는 online 목적함수로 quality와 few-step regime을 함께 최적화. (4) Entropy-bounded sampler + adaptive stopping으로 실제 denoising step을 12~15로 감소.
  • 비유: AR은 한 사람이 좌→우로 글자를 한 자씩 쓰는 것. Diffusion은 256글자 도화지를 흐릿한 상태에서 시작해 12번 정도 붓질하며 전체를 함께 다듬어 완성하는 방식이다. 매 붓질마다 모든 위치를 동시에 재검토할 수 있어 자기 수정과 미래 의존적 결정을 자연스럽게 처리한다.

핵심 기여 (Key Contributions)

  1. AR → Diffusion 변환의 실용 레시피: pretraining을 우회하고 fine-tuning만으로 discrete diffusion 모델을 얻는 2단계 파이프라인. Gemma 4의 10% 미만 토큰 예산으로 완료.
  2. ##SD·RL 통합 목적함수##: reward 최대화(quality)와 sampler distillation(few-step 압축)을 별도 스테이지 없이 단일 gradient update로 동시 최적화. 결과적으로 SD·RL 학습 중 reward는 상승하면서 effective denoising steps는 50 → 20으로 자연 감소.
  3. Block-Autoregressive 아키텍처: 인코더(causal attention, KV cache)와 디코더(bidirectional attention on 256-token canvas)를 같은 weights θ로 공유. Gemma 4의 causal AR 능력을 그대로 재활용하면서 diffusion 모드를 추가.
  4. Entropy-Bounded Sampler + Adaptive Stopping: MaskGIT류의 rank-order 토큰 커밋 대신 entropy 예산 b=0.1 하에서 낮은 entropy 토큰들부터 확정, 나머지는 uniform noise로 다시 렌더링. Confident + stable 조건에서 조기 종료로 평균 12 step만 수행.
  5. Speed-Intelligence Pareto Frontier: 단일 H100 FP8에서 1,479 TPS — Gemma 4 AR(204 TPS) 대비 7.1×, MTP 적용 AR(303 TPS) 대비 4.8×. Multimodal, thinking mode, long context 유지.
  6. Dual Mode: 파인튜닝 후에도 AR mode로 seamless 전환 가능. 하이브리드 diffusion-AR decoding 경로 개방.

배경: 왜 이 시점에 필요한가

AR LLM의 memory-bound 문제

현대 GPU 서빙에서 large LLM은 compute가 아니라 memory bandwidth가 병목이다. 매 forward pass마다 수십 GB의 weight와 KV cache를 HBM에서 accelerator로 옮겨야 하는데, single-token 생성은 accelerator의 연산 유닛을 대부분 idle 상태로 남겨둔다. Batching으로 총 throughput은 회복할 수 있으나 per-user latency는 여전히 나쁘다.

Speculative decoding: 작은 drafter 모델이 8 tokens를 미리 draft하고 큰 모델이 병렬로 verify → 3~6 TPF. 그러나 drafter가 여전히 sequential이며, blockwise/lookahead drafter는 후반 draft position에서 acceptance rate가 급락한다.

Text Diffusion의 등장과 한계

Diffusion은 전체 시퀀스를 병렬 refinement로 생성한다. 최근 모델들:

  • 폐쇄: Gemini Diffusion, Mercury 2 — API only, weights 미공개
  • 오픈 (early): LLaDA 2.1 Flash 100B, Nemotron-Labs-Diffusion 14B — 지능 또는 속도 어느 한쪽이 부족
  • Seed Diffusion, Fast-dVLM 등 — 특정 분야 특화

DiffusionGemma는 고지능 + 매우 빠름 + 완전 오픈 weights (Apache 2.0)를 동시에 달성한 첫 사례임을 주장한다.

Discrete Diffusion Framework (Section 2)

연속시간 Markov chain (CTMC) 기반

어휘 $\mathcal{V}$의 크기 $V$, canvas 길이 $C$. 시점 $t \in [0,1]$의 상태를 $x_t \in \mathcal{V}^C$로 표기. Marginal probability path는 clean $x_0 \sim p(\cdot)$부터 fully corrupted $x_1 \sim \text{Unif}(\mathcal{V}^C)$까지 부드럽게 보간.

Forward process (수식 1)

$$\mathbb{P}(X_t = x_t \mid X_0 = x_0) = \prod_{i=1}^{C}\left[\kappa_t \delta(x_t^i, x_0^i) + (1-\kappa_t)\frac{1}{V}\right] \tag{1}$$

여기서 $\kappa_t \in [0,1]$은 monotonically decreasing noise schedule($\kappa_0=1, \kappa_1=0$). 직관적으로 말하면, 시간이 지날수록 각 토큰이 어휘 전체에서 uniform하게 sample된 랜덤 토큰으로 대체될 확률이 커진다. 이는 BERT의 masking, ELECTRA의 replaced token detection과 계보가 닿는 multinomial(uniform) diffusion이며, 저자들이 masked diffusion보다 이 방식을 선택한 이유는 ##앞 step에서 잘못 sample된 토큰도 이후 step에서 재수정 가능##하기 때문.

Backward denoising (수식 2, 5, 6)

Reverse process는 학습된 posterior $p_\theta(\nu \mid x_t)$로 근사:

$$\mathbb{P}(X_{t-\Delta t} = \cdot \mid X_t = x_t) \approx \text{Step}(x_t, p_\theta(X_0 = \cdot \mid X_t = x_t)) \tag{2}$$

Decoder forward pass (수식 5)로 unnormalized logits $L_t$를 얻고, 수식 6에서 temperature scaling과 self-conditioning 업데이트:

$$\hat{p}_0 = \text{Softmax}(L_t/\tau_t), \quad z_{t-\Delta t} = \text{FFW}(\hat{p}_0 E), \quad x_{t-\Delta t} \sim \text{Step}(x_t, \hat{p}_0) \tag{6}$$

여기서 $E$는 토큰 embedding matrix, FFW는 self-conditioning FFN. Self-conditioning은 이전 step의 예측을 continuous 신호로 다음 step에 되먹인다. 이는 masked/uniform corruption이 조건부 독립을 가정해 발생시키는 local inconsistency — 예를 들어 위치 $i$가 위치 $j$의 동시 결정을 볼 수 없어 문법이 어긋나는 문제 — 를 완화하기 위함이다.

Architecture: Block-Autoregressive Encoder-Decoder (Section 3)

Shared-weight 인코더-디코더

DiffusionGemma는 encoder-decoder transformer이지만 단일 weights $\theta$를 공유한다. 이는 BART/T5의 bidirectional-encoder + causal-decoder와 구조가 역전된 형태이다:

구성Attention역할
EncoderCausal시스템 지시 + 사용자 입력 + 과거 canvases를 KV cache $H$로 인코딩
DecoderBidirectional (canvas 내) + cross-attn (KV cache)256-token canvas를 병렬 denoise

왜 causal encoder인가? 이 방향이면 새 canvas가 완성될 때마다 기존 KV cache를 재계산 없이 append만 하면 되어 long context에서도 확장성이 확보된다.

블록 AR 생성 프로세스 (Figure 4)

1. Context Encoding (causal encoder) input prompt → H = Encoder_θ(h) 2. Denoising Loop (bidirectional decoder × N steps) For n = 1..N: L_t ← Decoder_θ(x_t, z_t, H) x̂_0|t ← argmax(L_t) [현재 deterministic 예측] τ_t ← linear schedule (0.8 → 0.4) p̂_0 ← Softmax(L_t/τ_t) [entropy 계산 → adaptive stopping 체크] if stop: return x̂_0|t z_{t-Δt} ← FFW(p̂_0 E) [self-conditioning] [entropy-bounded token refinement] x_{t-Δt} ← 저entropy 위치는 sample, 나머지는 uniform 재렌더 3. Encode & Append H ← H ⊕ Encoder_θ(x̂_0) [완성된 canvas를 KV cache에 append] Repeat until end-of-turn token 생성

256 tokens씩 canvas 하나가 완성되면 그 결과는 영구히 freeze되고, 다음 canvas는 새 KV cache 위에서 시작. 이 block-AR 방식이 diffusion의 병렬성과 AR의 확장성을 결합한다.

Entropy-Bounded Sampler (Algorithm 1)

이 논문의 sampler는 MaskGIT의 rank-order 커밋 방식을 개선한 것으로, 다음과 같이 동작한다:

  1. Confident predictions: 각 위치 $i$의 entropy $e^i = \text{Entropy}(\hat{p}_0^i)$ 계산. 평균 $\bar{e}$가 $e_{\text{stop}}=0.005$ 이하이고 deterministic 예측이 이전 step과 같으면 early return.
  2. Entropy-bounded refinement: 낮은 entropy부터 순서대로 커밋. 누적 entropy가 budget $b=0.1$을 초과하기 직전까지의 토큰 집합 $U$만 sample에서 가져오고, $U^c$는 uniform noise로 다시 렌더링해 다음 step의 exploration을 유도.
  3. Temperature annealing: $\tau_{\max}=0.8$에서 $\tau_{\min}=0.4$로 linear anneal. 초기에는 다양성 탐색, 후반에는 고신뢰 커밋.

Figure 5는 이 adaptive stopping이 실제 downstream 태스크에서 N=48 최대 예산 중 평균 12 step만 사용됨을 보여준다. 어려운 태스크(LiveCodeBench, GPQA-Diamond)는 15~19 step, 쉬운 태스크(HumanEval, GSM8K)는 8~11 step으로 태스크 복잡도에 dynamic하게 적응한다.

Training Pipeline (Section 4~5)

Stage 1: Supervised Fine-tuning (Section 4)

Gemma 4 26B A4B checkpoint에서 초기화해 block-diagonal attention mask를 사용. 각 canvas에 대해 noise level $t \sim \text{Unif}[0,1]$을 sample하고 확률 $t$로 각 토큰을 noise. Cross-entropy loss:

$$L(\theta) = -\sum_{i=1}^{C} \log p_\theta(x_0^i \mid x_t, z_t, H) \tag{11}$$

Figures 6, 7의 관찰:

  • SFT 이전 모델은 denoising 불가능(성능 ≈ 0).
  • Non-thinking mode: 초기 SFT의 적은 양으로 빠르게 회복. 예컨대 GPQA-Diamond는 SFT 25% 지점에서 60%+ 성능.
  • Thinking mode: 더 긴 SFT 필요. Figure 7의 로그-선형 그래프에서 thinking 모드는 시작이 낮지만 slope가 steep해 학습 후반에 non-thinking을 추월. Reasoning trace의 stuttering/cycling 문제를 해소하기 위해 extended SFT가 필수적임을 시사.

Stage 2: Sampler Distillation + Reinforcement Learning (SD·RL) (Section 5)

SFT 후 모델은 많은 denoising step에서 좋은 성능을 보이나 ultra-low latency에 필요한 few-step regime에서는 quality가 붕괴한다. 이를 동시에 해결하는 것이 SD·RL의 목적.

전통적으로 quality alignment(RL)와 sampler compression(distillation)은 별개 스테이지로 처리했으나, DiffusionGemma는 online teacher가 매 step 생성한 trajectory 위에서 두 목적을 하나의 gradient로 통합:

  1. Reward maximization: 응답 품질을 높이는 표준 RL objective (helpfulness, math, code, IF)
  2. Sampler distillation: 이 고품질 output을 few-step regime으로 압축

Curriculum Effect (Figure 8)

SD·RL 학습 dynamics는 자연스러운 curriculum을 형성한다:

  • 초기: predictive entropy가 높아 adaptive stopping이 늦게 발동 → teacher가 긴 trajectory 생성 → 학습.
  • 후기: model confidence 상승 → entropy 감소 → adaptive stopping 조기 발동 → teacher가 더 짧은 trajectory로 옮겨감 → few-step regime에 자연스럽게 특화.

Figure 8: Reward Average가 0.27 → 0.38로 상승하는 동안 Effective Denoising Steps는 50 → 20으로 감소. 두 축이 동시에 개선되는 것이 SD·RL의 핵심 결과.

##Emergent Conciseness##

AR RL은 종종 응답을 길게 만드는 방향으로 reward를 maximizing한다. 반면 SD·RL은 반대로 predictive entropy 최소화 압박 때문에 더 짧고 토큰 효율적인 output을 생성. 최종 checkpoint의 total tokens가 SFT checkpoint의 거의 2배 더 짧다(Figure 9). 총 tokens 감소 × step per canvas 감소 → end-to-end latency에 곱셈적 이득.

Bidirectional Reasoning & Self-Correction (Section 9.1)

AR은 다단계 산술 문제에서 답을 중간 계산 이전에 먼저 커밋해야 하는 부담이 있다. 예로 "(어떤 계산) = ?"의 답 자리에 AR은 sequential하게 −1을 커밋했다가 이후 계산을 봤을 때 이를 수정할 수 없다. DiffusionGemma는 canvas의 후반 토큰이 초반 토큰에 영향을 주며 병렬 진화하므로 answer와 reasoning이 공진화한다. 논문 Figure 15는 초기 잘못된 −1 예측이 iteration을 거치며 최종 −25로 수렴하는 과정을 보여준다.

비판적 분석 (Critical Analysis)

강점

  • AR fine-tuning 비용의 10% 미만으로 diffusion mode를 활성화한 것은 실무적으로 커다란 이정표. 다른 팀들이 pretraining부터 다시 하는 접근을 시도할 때 이 논문은 기존 AR weights의 재사용성을 강하게 논증.
  • SD·RL의 통합 objective는 curriculum이 자연 발생한다는 특성이 매우 우아하다. Entropy 감소 → adaptive stopping 조기화 → teacher trajectory 축소의 자기 강화 루프.
  • Emergent conciseness는 AR RL의 length-hacking 문제를 우회하는 예상치 못한 이득. 실무적으로 매우 유용.
  • Dual mode(AR + Diffusion) 유지로 hybrid decoding 경로가 열림. Task-dependent routing이 가능해진다.
  • Open-weights Apache 2.0 배포로 재현성과 확장성 확보. 이미 다운스트림 SFT toolkit이 함께 릴리스됨.

한계와 의문점

  • Absolute quality gap: TD mode는 AR mode 대비 여전히 3~15점 뒤진다. AIME 2026: 69.1 vs 84.2, LCB-v6: 69.1 vs 71.4. 폐쇄 모델 Mercury 2 High에는 대부분 벤치에서 뒤짐. Speed를 위해 지능을 얼마나 희생했는가에 대한 정직한 회계가 필요.
  • Batch size scaling의 취약함: c=32+에서 AR (MTP)이 역전. 대규모 서빙 환경(chatbot 서비스)에는 여전히 AR이 더 효율적일 수 있다. Diffusion의 우위 영역이 low-batch에 제한됨.
  • MoE 재사용의 우연성: DiffusionGemma는 canvas당 84 experts activate. 이는 memory bandwidth를 상당 부분 소진하는 결과. 만약 base 모델이 Dense였다면 결과가 어땠을지 미확인. 저자들 스스로 "Dense였다면 FFN 오버헤드가 2× 미만이었을 것"이라 언급.
  • Sampling kernel 미최적화: sampling이 3.06ms로 전체의 24%. Custom CUDA kernel로 최적화 여지가 큼. 현재 결과는 여전히 conservative일 가능성.
  • Thinking mode의 이해가 부족: MMLU-Pro 등 knowledge task에서 thinking이 −11.7점 해가 되는 이유가 분석되지 않음. Diffusion 특유의 무엇이 knowledge recall과 상충하는가?
  • Adaptive stopping의 안정성: entropy threshold 0.005, budget 0.1 등 하이퍼파라미터의 sensitivity ablation 부재. Domain shift 시 이 값들이 어떻게 무너지는가는 미검증.
  • Long context에서의 검증 부족: canvas 256 × K개 append 방식이 32K+ context에서도 quality가 유지되는지에 대한 실증이 약함.

실무 관점 트레이드오프

  • 대화형 UI, 에이전트 워크플로우, IDE 어시스턴트 등 latency-critical + low-concurrency 시나리오에 강력한 후보.
  • 대규모 chatbot 서비스는 여전히 AR (MTP)이 유리할 가능성. Diffusion으로 마이그레이션은 시나리오 검증 필수.
  • 다운스트림 SFT (LoRA rank 8)만으로 domain-specific 능력 획득 가능. Compute barrier가 낮아 커뮤니티 확산 예상.

Key Takeaways: 이 논문에서 가져갈 것

  • AR → Diffusion 변환은 실용적이다: pretraining 없이 10% 예산 fine-tune으로 diffusion mode를 켤 수 있다. 다른 오픈 AR 모델(Qwen, DeepSeek 등)로의 이식 가능성이 열림.
  • SD·RL의 통합 objective 아이디어: sampler compression과 quality alignment를 별개 stage로 두지 말 것. Curriculum이 자연 발생한다.
  • Entropy-bounded sampler + adaptive stopping은 diffusion inference의 새 표준 후보. Task complexity에 dynamic하게 적응하며 12~15 step으로 수렴.
  • Emergent conciseness: SD·RL은 AR RL과 달리 응답을 길게 만들지 않는다. Diffusion RL의 유리한 편향.
  • Text diffusion의 sweet spot은 low-batch, latency-critical 시나리오: 서빙 아키텍처 설계 시 명확한 지침이 됨.
  • Dual mode 유지 전략: fine-tune 후에도 AR mode를 잃지 않도록 하는 것이 실용성의 관건.
  • Puzzle/constraint satisfaction 태스크에 이상적: Sudoku 실험이 이 방향성을 입증. Non-sequential 문제 해결에 유망.
