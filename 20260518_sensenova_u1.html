TL;DR

  • 문제: 현재의 vision-language model은 ##understanding과 generation을 별개의 시스템##으로 다룬다 — understanding은 vision encoder(VE)가 매개하고, generation은 VAE latent를 사용. 이 dichotomy는 ##fragmented architecture, cascaded pipeline, misaligned representation space##를 만들어 native multimodal intelligence의 emergence를 막는다.
  • 해결: SenseNova-U1은 NEO-unify를 scale-up한 ##native unified multimodal paradigm##. ##VE도 VAE도 없이## raw pixel과 word를 직접 다룬다. (1) Near-lossless visual interface (16×16 conv encoding, MLP decoding, 32× compression), (2) Native Mixture-of-Transformers (MoT) — understanding stream과 generation stream이 ##모든 layer에서 interact##, (3) end-to-end pixel-space autoregressive cross-entropy + flow matching joint objective.
  • 왜 작동하는가: VE/VAE의 pretrained semantic bias와 compression bottleneck이 ##capacity trade-off의 진짜 원인##. 그 layer를 제거하면 ##representation space가 자유롭게 application에 맞춰 self-organize##된다. ##encoder-free design이 semantic + pixel representation을 동시 보존##.
  • 비유: 통역사(VE) 한 명이 두 언어를 옮기는 시스템에서, ##두 언어를 native로 같이 키운 bilingual speaker##로 전환. 두 capability가 분리된 시스템이 아니라 ##한 underlying process의 synergistic view##.

핵심 기여 (Key Contributions)

  1. NEO-unify 기반 native unified paradigm: ##VE와 VAE 동시 제거##한 최초의 강력한 unified VLM 중 하나. 16×16 stride conv encoding + MLP-like patch decoding, ##32× compression ratio##에서도 native semantic + pixel fidelity 유지.
  2. Native Mixture-of-Transformers (MoT): understanding stream(clean image+text)과 generation stream(noise-conditioned)이 ##shared self-attention##을 매 layer 거치며 interact. Full parameter decoupling — projections, normalizations, feedforward block은 ##token type에 따라 dynamic routing##. 두 스트림이 monolithic하게 작동.
  3. 두 가지 scale: ##SenseNova-U1-8B-MoT## (dense 8B, 42 layers, pre-buffer layers 포함) and ##SenseNova-U1-A3B-MoT## (30B-A3B MoE, 128/32 experts for und/gen, 48 layers, ##8 active experts per token##, ~3B active param). 같은 paradigm이 dense와 sparse 양쪽에 확장 가능.
  4. 5-stage Training Recipe: ##Stage 1 (Understanding Warmup)## → ##Stage 2 (Generation Pre-Training, 3 phases)## → ##Stage 3 (Unified Mid-Training)## → ##Stage 4 (Unified SFT)## → ##Stage 5 (Post-Training: Flow-GRPO + DMD)##. 누적 ##1.19T training tokens## for unified mid-training.
  5. 광범위한 SOTA: GenEval ##0.91## (8B/8BA3B both, open-source SOTA), DPG-Bench ##88.14/87.78##, OneIG-EN ##0.549/0.543##, CVTG-2K word accuracy ##0.940## (closed-source 능가), LongText-Bench-EN ##0.979##, WISE ##0.81## (open-source top), Uni-MMMU GaU ##35.0## (BAGEL/Ovis 능가).
  6. Disaggregated inference architecture: ##LightLLM (understanding+streaming)## + ##LightX2V (generation)## 두 specialized engine. Pinned shared memory로 state 교환. ##colocate / separate 양 모드 지원##.
  7. Distribution Matching Distillation: T2I post-training에서 NFE를 ##100 → 8##로 축소. 100M-step 학습 후 8-step inference가 가능한 production-ready efficiency.

배경 (Background)

VLM의 두 가지 진화 방향

2022년 이후 vision-language model이 두 distinct direction으로 분화:

  • Discrete unified models (Show-o, Janus, Tuna, OmniGen, BAGEL 등): 모든 modality를 ##discrete token으로 변환##해 single autoregressive framework. seamless cross-modal reasoning이 가능하지만 ##non-linguistic signal이 lossy하게 compressed##되어 visual fidelity 제약.
  • Continuous unified models: ##continuous representation 기반의 shared space##. high-fidelity 재구성이 가능하지만 understanding-generation 사이 ##semantic abstraction vs pixel granularity의 tension## 미해결.

NEO-unify의 출발점

NEO (Wang et al.)는 ##native VLM primitive##를 제안 — VE 없이 pretrained representation에 의존하지 않고 vision perception을 self-organize. 이를 generation으로 확장한 것이 NEO-unify. 본 paper는 ##NEO-unify를 8B/30B-A3B scale로 키우고## 5-stage 학습 레시피를 fully document.

왜 VE/VAE 제거가 어려운가

VE (CLIP, SigLIP, DINOv2)는 ##discriminative pretraining objective##에서 학습되어 ##high-level semantic feature##만 retain하고 fine-grained pixel detail은 lossy. VAE는 ##low-dimensional latent로 압축##해 generation의 efficient flow matching을 가능하게 하지만 ##semantic structure가 약화##. 두 모듈이 ##대립되는 inductive bias##를 imposing해 unified model은 항상 그 사이 trade-off를 감내해야 했다.

방법 (Method): 3-Layer Architecture

Layer 1: Near-Lossless Visual Interface

Patch Encoding Layer

입력 image (또는 noise)를 ##2-layer convolution (GELU activation, 2D sinusoidal positional encoding)##로 visual token으로 매핑. Conv stride 16, 16 → 32×32 image patch 하나가 하나의 visual token으로. ##<img>/</img> special token##으로 visual content delimit.

중요: ##downsampling ratio 32##인데도 unified model이 strong understanding+generation을 유지. 이는 token-level pixel-word correspondence를 deeply correlated learning으로 보상.

Patch Decoding Layer

  • Understanding stream: linear projection head → token-to-vocabulary.
  • Generation stream: ##multi-layer MLP head로 pixel patch 직접 예측##. ##diffusion head나 VAE decoder를 우회##.

Dynamic Noise Scale

Generation stream이 ##varying resolution##에서 작동하므로 naive unit-variance prior $z_1 \sim \mathcal{N}(0, I)$가 signal scale과 mismatch. Resolution-adaptive noise scale:

$$\sigma_R(H,W) = \sigma_0 \sqrt{N(H,W) / N_0} \quad (\text{NSEmb})$$

$N(H,W) = (H \cdot W)/32^2$는 generation token 수, $N_0$는 reference count. 직관적으로 말하면, ##고해상도 image는 더 많은 noise를 받아야## per-token noise energy가 일정하게 유지. Conditioning signal:

$$s_t = \tau_t + \text{NSEmb}(\tilde\sigma(H,W)), \quad \tilde\sigma = \sigma_R/\sigma_\max \in [0,1]$$

Layer 2: Native Mixture-of-Transformers (MoT)

Improved Native Primitive

Native RoPE multi-axis: text token은 ##temporal axis T##만 사용 (H=W=0), image token은 ##추가로 spatial axes H, W##. Q/K projection의 head dimension을 T, H, W로 ##reallocate##, 각각 independent frequency base. 텍스트와 비주얼 modeling을 단일 unified attention 안에서 native하게 지원.

Two Streams, One Sequence

Understanding stream과 generation stream은 ##모든 layer에서 shared self-attention##:

  • Clean image와 text는 understanding stream으로 처리 (causal w.r.t. text, bidirectional within image block).
  • Noise-conditioned input은 generation stream으로 (noise tokens가 same image block 안에서 bidirectional, full access to clean inputs).
  • Clean tokens는 noise tokens로부터 attend하지 못함 (prevent leak).

##Full parameter decoupling##: 두 stream은 ##separate projections, normalizations, feedforward block##을 가지며 ##각 layer에서 token type에 따라 dynamic routing##.

Layer 3: Joint Training Objective

Total Loss (Equation 1)

$$\mathcal{L}_\text{total} = \lambda_1 \mathcal{L}_\text{Und} + \lambda_2 \mathcal{L}_\text{Gen}$$

Autoregressive Text Loss (Equation 2)

$$\mathcal{L}_\text{Und} = -\frac{1}{N}\sum_{n=1}^{N} \log p_\theta(x_n | x_{<n}, c)$$

표준 next-token prediction.

Pixel-Space Flow Matching (Equations 3–5)

JiT-style x-predict + v-loss. Clean image $\mathbf{x}$와 Gaussian sample $\boldsymbol\epsilon \sim \mathcal{N}(0, I)$:

$$\mathbf{z}_t = t \mathbf{x} + (1-t) \sigma_R \boldsymbol\epsilon, \quad t \in [0,1] \quad (3)$$

$t=0$이 pure noise, $t=1$이 clean image. Velocity term:

$$\mathbf{v}_\theta(\mathbf{z}_t, t) = \frac{\hat{\mathbf{x}}_\theta(\mathbf{z}_t, t, \mathbf{s}_t) - \mathbf{z}_t}{1-t} \quad (4)$$

MSE 형태 loss:

$$\mathcal{L}_\text{Gen} = \mathbb{E}_{t, \mathbf{x}, \boldsymbol\epsilon, (H,W)}\left[ \|\mathbf{v}_\theta(\mathbf{z}_t, t) - \mathbf{v}^\star\|_2^2 \right], \quad \mathbf{v}^\star = \frac{\mathbf{x} - \mathbf{z}_t}{1-t} \quad (5)$$

직관적으로 말하면, model이 ##noise → clean trajectory의 velocity##를 학습.

Unified Classifier-Free Guidance (Equation 6)

Text condition $c_\text{txt}$와 image context $c_\text{img}$를 ##independently modulate##:

$$\nabla_\mathbf{x} \log p(\mathbf{x} | c_\text{img}, c_\text{txt}) = \gamma(\nabla_\mathbf{x} \log p(\mathbf{x}|c_\text{img}, c_\text{txt}) - \nabla_\mathbf{x} \log p(\mathbf{x}|c_\text{img})) + \gamma_\text{img}(\nabla_\mathbf{x} \log p(\mathbf{x}|c_\text{img}) - \nabla_\mathbf{x} \log p(\mathbf{x})) + \nabla_\mathbf{x} \log p(\mathbf{x})$$

Training 중 text를 10% drop, text+image를 추가 10% drop. Empirically $\gamma=4, \gamma_\text{img}=1$이 best — ##model이 visual conditioning은 effectively capture, text alignment에 더 강한 guidance 필요##.

Stage 1: Understanding Warmup

Pretrained NEO에서 초기화. 2-phase:

  • Attention-Fusion Phase: NEO의 QK projection과 normalization을 ##temporal axis와 spatial axes에 걸쳐 single shared set으로 unify## (QK parameter footprint를 절반으로). RoPE frequency: temporal $\theta=5{,}000{,}000$, spatial $\theta=10{,}000$. ##기존 network는 freeze, attention layer만 fine-tune##.
  • Full-Model Continuation Phase: 전체 understanding branch unfreeze, mid-training corpus로 LR 2e-5. SenseNova-U1의 ##understanding backbone## 구축.

Stage 2: Generation Pre-Training (3 Phases)

  • Phase I: text-to-image data 256²~1024² resolution, constant LR 2e-4, 120K steps.
  • Phase II: resolution ≥ 512², 60K steps, LR 1e-4.
  • Phase III: editing + reasoning + interleaved image-text generation 추가, 120K steps, cosine LR 1e-4 → 2e-5.

A3B variant는 MoE balance loss coefficient $5 \times 10^{-3}$.

Stage 3 & 4: Unified Joint Training

Both branches가 ##end-to-end jointly optimize##. Data sampling ratio: understanding 0.33, generation 0.37, editing 0.24, interleave 0.06. Loss weights $\lambda_1=0.1, \lambda_2=1.0$ (generation이 dominate). Stage 4 SFT는 ##9K steps##로 더 짧고 carefully curated data로 instruction alignment.

Stage 5: Post-Training for T2I

##Flow-GRPO##를 사용한 RL: text rendering reward (PaddleOCR IoU), style following reward (VLM judge), aesthetic reward (HPSv3). 두 reward group 교대 학습:

  • Group 1: text rendering + style ($r = r_\text{ocr} + \lambda_\text{sty} r_\text{sty}$, $\lambda_\text{sty}=0.5$).
  • Group 2: aesthetic only.

Dynamic resolution warmup: difficulty score 기반 gated sampling (Equation 7). 8B variant 1,600 epochs, A3B variant 200 epochs.

Stage 6: CFG & Step Distillation (DMD2)

Distribution Matching Distillation v2로 NFE ##100 → 8##. Three model: generator $G$, fake flow model $F$, teacher $T$ (모두 teacher에서 initialize). $G$는 ##5 update of $F$마다 1번 update##. AdamW lr 2e-6 (G), 4e-7 (F).

Inference Infrastructure: Disaggregated Deployment

두 specialized open-source engine:

  • LightLLM: multimodal understanding, text streaming, request orchestration. LLM-oriented tensor parallelism (TP).
  • LightX2V: image generation. Diffusion-oriented (CFG parallelism, sequence parallelism).

두 engine이 ##pinned shared memory##로 generation state 교환. Three practical benefits: (1) different parallelism per workload, (2) independent resource budget, (3) operational isolation.

Hybrid Attention Kernel

Unified multimodal prefill의 system challenge: text rows는 causal, image rows는 ##full text prefix + full image span##에 attend. ##Optional b_image_token_end##로 M-block 단위 masking decision: image token이 있으면 key range를 image-span end까지 확장, 없으면 causal fast path. Triton kernel + modified FlashAttention3 두 backend.

##Native MoT design이 strong data-scaling efficiency를 보임##. understanding-generation synergy가 token 증가에 따라 향상.

비판적 분석 (Critical Analysis)

  • 학습 cost 미공개: 1.19T mid-training token 외에 generation pre-training이 0.25T+0.25T+0.88T = 1.38T, 거기에 understanding warmup 0.75T까지 = ##총 3T+ training tokens##. ##GPU hour 비용, 사용 H100 수##가 명시되지 않음. 학원 규모 재현이 거의 불가능.
  • 저자 익명/대규모 단체 저작: 100+ contributor 단체 발행. ##peer review에서의 개별 책임 추적이 어렵고## individual ablation에 대한 깊이 있는 토론이 부족.
  • Encoder-free design의 일부 약점 인정: InfoVQA에서 Qwen3VL-8B 86.00 vs U1-8B 82.46 — ##일부 fine-grained OCR task에서는 VE 기반 모델이 우세##. paper는 이를 솔직히 보고하지만, ##모든 task에서 encoder-free가 우월##하다는 message는 과장.
  • 32× compression의 정량적 cost: image generation에서 fine detail이 손상되는 case (예: tiny text, dense pattern)에 대한 ##failure mode 분석##이 부족. CVTG-2K 같은 text rendering benchmark에서는 0.940으로 우수하지만, ##very dense visual element##에서는 어떤지 미명시.
  • 5-stage training의 부분 ablation: 각 stage의 individual contribution이 fully ablated되지 않음. ##Stage 5 RL post-training의 contribution##이 GenEval/DPG benchmark 수치에 얼마나 영향을 주었는지 명확한 ablation 없음.
  • Inference cost와 latency 측정 부족: 8 NFE distillation 후의 ##absolute latency##가 production-relevant하지만, 다양한 resolution에서의 end-to-end time이 부분적으로만 보고됨. 2048×2048 in separate mode: 0.415s (5090) / 0.443s (L40S) — 다른 resolution에 대한 표준화된 표가 없음.
  • BizGenEval 절대값이 낮음: 39.7/61.7 hard/easy로 open-source SOTA지만 closed-source SOTA(GPT-Image-2 82.1/92.5)와 ##큰 격차##. ##complex commercial scenario에서 unified model이 still gap을 보인다##는 점을 인정.
  • VLA/WM 주장의 preliminary nature: vision-language-action과 world modeling 결과가 ##preliminary evidence##라고만 명시되며 quantitative benchmark가 없음. 향후 검증이 필요.
  • Image editing이 specialized model에 비해 약함: Qwen-Image-Edit-2511 (20B) 4.51 vs U1-8B 3.90 — ##specialized editing model이 여전히 advantage##. paper는 이를 "editing data가 open-source resource에 dominated되어 있다"고 설명하지만, unified model의 ##본질적 trade-off##일 수 있음.

Key Takeaways

  • "VE/VAE 제거가 multimodal AI의 next paradigm": pretrained semantic prior에 의존하지 않고 ##raw pixel/word로부터 representation을 자유롭게 self-organize##시키는 디자인이 unified model의 long-standing trade-off를 깨는 방향. SenseNova-U1은 이 가설을 ##8B/30B scale에서 처음으로 실증##.
  • "Native MoT는 colocation이 아니라 synergy를 만든다": Understanding stream과 generation stream이 모든 layer에서 shared self-attention으로 interact하면서도 ##fully decoupled parameters##를 가져 minimal interference. Uni-MMMU의 GaU/UEG 결과가 ##genuine bidirectional synergy##를 정량 입증.
  • "32× compression이 가능하다 (조건부)": visual interface 자체는 highly compressed지만 ##deeply correlated learning이 token-level pixel-word correspondence를 효과적으로 보상##. 그러나 fine-grained OCR 같은 일부 task에서는 ##VE 기반이 여전히 우월##.
  • "Text rendering이 open-source SOTA에 도달": CVTG-2K 0.940, LongText-Bench 0.979 — ##multilingual long-form text rendering이 closed-source SOTA를 넘어선 첫 open-source 결과##. 디자인/포스터/인포그래픽 application에 직접 응용 가능.
  • "Reasoning-driven generation의 CoT 효과": WISE/RISEBench에서 ##CoT 활성화 시 logical/causal 차원에서 큰 향상## (RISEBench Logical 7.1 → 20.0). 이는 explicit reasoning이 ##generation pipeline의 새 control surface##임을 시사.
  • "Data-scaling efficiency가 native design의 진짜 검증": T2I-Reasoning이 0→2.5T tokens에서 40 → 67로 단조 향상. ##unified MoT가 data scale에 잘 반응##하는 것이 architecture choice의 정당성을 시간 차원에서 입증.
  • "Disaggregated inference가 unified model의 production-ready 디자인": LightLLM (understanding) + LightX2V (generation) 분리는 ##두 workload의 parallelism 전략과 resource budget이 독립##임을 인정하는 실용적 architecture. unified model을 monolithic하게 serve하려는 잘못된 instinct에 대한 corrective.
