TL;DR

  • 문제: 프론티어 언어모델은 (a) long-horizon agent 시나리오에서 수십만~수백만 토큰의 trajectory를 하나의 컨텍스트에 담아야 하는데 softmax attention은 KV cache가 선형·계산이 quadratic으로 폭증, (b) 한국어 sovereign AI라는 목표 하에 pretraining budget 제한 (250B 모델 × from scratch는 비쌈), (c) 12개 도메인 전문가를 만들었을 때 한 모델로 consolidate하는 표준적 방법 (SFT distillation)이 off-policy · exposure-bias 문제로 실패한다.
  • 해결: 250B-A15B MoE. 세 가지 축의 기여 — (1) Hybrid attention stack: 4-layer 블록마다 softmax 1개 + linear (KDA) 3개 (S-L-L-L 순서), NoPE, negative eigenvalue extension으로 1M context 달성. (2) Selective weight transfer: Solar Open 1 (102B)에서 backbone과 호환되는 5.69B (2.3%) 파라미터만 이식하고 나머지는 randomly init → same-loss 도달에 ~1.7× 토큰 절감. (3) Multi-Teacher On-Policy Distillation (MOPD): 12개 domain specialist를 KL-only student self-rollout으로 통합 → capability 손실 없이 하나의 모델로 fold.
  • 왜 작동하는가: Linear attention은 fixed-size recurrent state로 순서 정보를 encoding하므로 NoPE와 결합해 softmax의 positional-encoding bottleneck 제거. Negative eigenvalue (β=2σ, [-1,1])는 state-tracking 능력 복원. Softmax layer는 exact global recall을 유지해 pure linear의 한계 보완. Selective transfer는 architectural change를 넘는 partial warm start.
  • 비유: "책의 목차(softmax)와 색인(linear)"을 함께 두는 방식. 순차 넘김에는 linear가 강하고, 특정 페이지 정확한 인용은 softmax가 필요 — 3:1로 섞어 두 장점 모두 확보. 그리고 학교(pretraining)를 다시 다닐 필요 없이 기존 학위(Solar Open 1)의 학점 일부만 인정받고 새 학위(Solar Open 2)를 받는 방식이 selective weight transfer.

핵심 기여 (Key Contributions)

  1. 1M-context Hybrid Attention Stack: 48 layers 중 12 softmax + 36 linear (25%/75%). Block당 S-L-L-L 순서로 12회 반복. GQA (64/8, sigmoid output gate) + KDA (Kimi Delta Attention with negative eigenvalue). ##NoPE로 positional encoding 완전 제거## — linear state가 순서 정보를 담아 1M+ context 자연 확장.
  2. Selective Weight Transfer: Solar Open 1 (102B) → Solar Open 2 (250B)로 총 5.69B (2.3%) 파라미터 이식. Token embedding, softmax attention의 $q/k/v/o$ projection, shared expert 등 shape-compatible 부분만 direct transfer. Random init 대비 same-CE-loss 도달에 1.7× 토큰 절감 (200B-A15B 프록시에서 12.6B vs 21.5B).
  3. Quality/Rarity-Aware Data Curation + 4-stage Curriculum: 20T pool → 10T 소비. Stage 2 (10T) + Stage 3 (Intensive, 1T, 재필터링 후 재학습) + Stage 4 (Length Expansion, 0.9T, 1M context). 4개 중간 checkpoint를 평균해 최종 PLM. Solar Open 1 recipe 대비 en_code +21.6%p, ko_math +20.4%p, en_math +14.6%p 개선.
  4. Purpose-built Agent Scenarios: General conversational (MCP-based tool, live transactional DB), Coding (SWE/terminal/artifact, diverse scaffolds), Officework (OfficeVerse: 11 industry × 12 task types, verifier-first). Ko-GDPval (한국 사무 에이전트 벤치) 정성 배포.
  5. Multi-Teacher On-Policy Distillation (MOPD): 12명 specialist teacher를 KL-only student self-rollout으로 통합. Teacher placement, dense signal without $[L\times V]$ blow-up (pre-lm_head hidden state 전송), transport CP-aware, pool management (1 GPU-resident + 12 CPU snapshots) — 시스템 4대 문제 해결.
  6. Fully Asynchronous RL: Trainer/Actor 분리, fresh-token-fraction gateway (staleness control), length/staleness-aware batch sampling, direct double-sided importance sampling, environment-failure filtering + group-size repair. Long-tail trajectory 문제 해결.
  7. 한국어 SOTA: Korean suite 평균 85.4, DeepSeek-V4-Flash (84.9) 및 fast-tier closed API (GPT-5.4 mini 80.8, Claude Haiku 4.5 69.6) 능가. Ko-GDPval 86.8 — DeepSeek-V4-Pro (1.6T) 86.9와 사실상 동률 모델 크기 1/6.4.

배경 지식 (Background)

Softmax vs. Linear Attention

Softmax attention은 각 query가 모든 key와 dot product 후 softmax normalization → KV cache 크기 $O(L)$, 계산 $O(L^2)$. 반면 linear attention은 attention을 kernel decomposition으로 근사해 fixed-size recurrent state로 압축 → KV cache $O(1)$, 계산 $O(L)$. 대가로 recall이 부정확해 특정 위치의 정확한 fact 재현에 취약.

Kimi Delta Attention (KDA)

Yang et al. 2025의 gated delta rule 기반 linear attention. State transition에 delta update 규칙을 도입 (기존 정보를 덮어쓰는 erase term $\beta k k^\top S$ + 새 정보 쓰기 $\beta k v^\top$). $\beta$가 write strength를 조절. 기본 KDA는 $\beta \in [0,1]$로 allow_neg_eigval=False — 즉 state가 decay만 가능, sign flip 불가. 이 제약이 state-tracking 문제 (parity, modular counting 등)를 이론상 풀 수 없게 만든다 (Grazzi et al. 2025).

Negative Eigenvalue Extension (β=2σ, [-1,1])

Solar Open 2는 $\beta = 2\sigma(\cdot) \in (0,2)$로 확장 (erase term과 write term에 동일 적용). 이로써 eigenvalue range가 $[-1, 1]$로 확대 → state가 sign flip과 self-correct 가능. Linear-heavy NoPE 설계에서 이는 필수적 — softmax layer에 positional signal이 없으므로 linear state가 유일한 order carrier로서 drift 없이 1M 토큰 유지해야 함.

Sigmoid Output Gate (Qiu et al. 2025)

Softmax attention의 output에 element-wise sigmoid gate 곱. (1) low-rank softmax mapping에 non-linearity 부여, (2) attention output을 query-dependently sparse하게, (3) attention sink (초반 몇 토큰에 attention이 collapse)를 억제. 안정적 큰 LR + long-context extrapolation 강화.

NoPE (No Positional Encoding)

RoPE 같은 explicit positional signal은 training length distribution에 tied → extrapolation limit. NoPE는 positional encoding을 완전히 제거. Softmax layer는 순서를 학습으로 획득 (relative position), linear layer는 sequential state로 intrinsic 순서 encoding. RoPE extrapolation 한계와 softmax의 position-learning bottleneck 모두 제거.

선택 원칙 3가지:

  1. Token embedding/output layer: vocab이 identical하므로 학습된 token semantics 그대로 이식
  2. Normalization: training stability를 위해 이식
  3. Softmax attention $q/k/v/o$: Solar Open 2가 Solar Open 1의 GQA geometry (64 query, 8 KV head) 그대로 유지 → clean transfer
  4. Linear attention의 $q/o$만 GQA에서 re-map (64 heads match). $k/v$ 및 decay/write gate는 counterpart 없음 → random
  5. Sigmoid output gate: new component
  6. Routed experts: 128 → 320 확장. Replicating experts를 채우면 inter-expert similarity가 증가해 specialization 손실 → random init 선택

Ablation (Figure 6): 200B-A15B proxy에서 initialization만 다르게 학습. Training CE 1.8 도달에 selective transfer는 12.6B 토큰, random init는 21.5B 토큰 (약 1.7× fewer, 58%). Loss 2.6에서는 1.15×, loss 1.8로 갈수록 격차 확대 → transfer benefit이 깊은 loss로 갈수록 축적됨.

3.3 Curriculum Learning (Figure 8)

Stage 1: Selective Weight Transfer (weight init ~2.3% from Solar Open 1) Stage 2: General Pre-training (10T tokens, broad-coverage high-quality) Stage 3: Intensive Pre-training (1T tokens, higher quality threshold, revisit best 1T of Stage 2) Stage 4: Length Expansion (0.9T tokens, context 1M, long-doc + repo-level code) Merge: 4 intermediate checkpoint를 shard-wise 평균 → 0.745 avg PLM score (best single checkpoint 대비 개선)

Stage 2 (10T)에서 PLM 50+ metric 평균이 rise 후 stagnate. Stage 3 (1T)에서 다시 상승. Stage 4 (0.9T)에서 length distribution shift로 slight degradation. Checkpoint merge가 이 drop을 회복 → 0.745 avg PLM (Stage 3 최고보다 향상).

4. Post-training

[Figure 9 설명]: 4-stage post-training pipeline. (1) SFT (chat template + reasoning + agent tasks) → (2) Multi-domain RL (verifiable rewards on STEM) → (3) Specialist (12명 domain teacher를 각각 SFT + domain-specific RL로 훈련) → (4) MOPD (12 teacher를 하나의 student로 consolidation).

4.1 Agent Scenarios

General Conversational Agent:

  • MCP-based tool over stateful envs + policy-bound conversation over live transactional domain
  • Verifier-first: mutation을 live env에 실행 → expected state effect 기록 → sandboxed pytest suite (env read tools 위) 합성
  • Task instructions는 controlled obfuscation level로 rewrite → agent가 transcription 아닌 discovery로 해결
  • 3-pass self-consistency verification: hard trace rules + LLM coherence judge + executable read-back
  • Live transactional DB에 대한 user simulator (Cho et al. 2026)로 policy semantics 학습

Coding Agent (SWE + terminal + artifact):

  • SWE: 18개 언어의 pull request mining → problem statement + gold patch + test patch + base commit + env req. LLM-synthesized Docker env가 buildable and fail-to-pass인 경우만 admit
  • Diverse scaffolds (OpenHands, Claude Code, OpenCode, KiloCode, HermesAgent)로 rollout → single-scaffold overfit 방지
  • Terminal: 10+ 도메인 (data science, scientific computing). Self-verification 강조: agent가 code-level self-test 작성 → 실패 시 revise & re-test until pass
  • Artifact (front-end): 6 카테고리 (website, game, 3D, data viz, UI, SVG). Vendi Score 최대화로 seed dedup + clustering. VLM-as-judge로 full-page screenshot의 기능적/시각적 완결성 평가

Officework Agent (OfficeVerse):

  • 11 industry × 12 task type (analysis→xlsx, presentation→pptx 등)의 132-cell 매트릭스
  • Atomic occupational task synthesis (4-stage): context → supplementary-data → prompt → rubric generation. 각 stage에 deterministic validation gate.
  • World-grounded workspace synthesis: real 회사의 project tree를 seed로 heterogeneous material 배치. Task prompt는 file path 등을 withhold → agent가 retrieval + cross-file synthesis로 해결
  • Environment-quality audit: shortcut solvable한 instance (single obvious file, parametric recall) reject
  • 2-axis control: difficulty (constraint 살아남는 정도) + expertise curriculum (scaffolding 점진 제거)
  • 한국어 officework: Korean occupational taxonomy + Korean business-writing conventions (native numeric units, standard domain terminology, Korean-style file naming) + English-reasoning/Korean-output language protocol + CJK rendering integrity checks

4.2.1 Fully Asynchronous RL

5-component 설계:

  1. Disaggregated arch with in-flight weight updates: Trainer/Actor 분리된 GPU pool. Actor는 지속적 trajectory 생성, buffer가 차면 batch dispatch. Trainer가 새 weight publish 시 in-flight generation 잠시 suspend, weight broadcast, KV cache recompute → resume. Single trajectory는 여러 successive policy version으로부터 segment 포함 가능 (per-token metadata로 tracking)
  2. Fresh-token-fraction gateway: 각 token이 자신이 생성된 policy version 기록. 현재 학습 policy 대비 gap이 $s_{\text{max}}$ 이하이면 fresh. Trajectory의 fresh-token ratio가 threshold $\rho$ 이상이면 admit (stale prefix는 loss에서 mask). 이하면 discard. Long expensive trajectory를 통째로 버리는 대신 salvage (Figure 10)
  3. Length- and staleness-aware batch sampling: FIFO sampling은 length-skewed distribution (short trajectory 먼저) 유발. Pre-generate $N \times$ batch size, sort by length + partition into $\lfloor|\text{buffer}|/|\text{batch}|\rfloor$ bins, 1 trajectory per bin per step. 각 bin에서는 stalest 먼저 (Figure 11)
  4. Direct double-sided importance sampling (Zeng et al. 2026): Token-level ratio를 rollout policy 대비 double-sided trust region 안팎에서 판단 → 안쪽만 update contributes. GSPO의 sequence-level ratio 대신 GRPO의 token-level 유지 (여러 policy version 혼합 가능성 반영)
  5. Environment-failure filtering + group-size repair: Sandboxed env의 file-system error, container crash 등은 policy fault가 아님. Failure reason logging → env-attributable 제외. GRPO group의 절반 이상 valid하면 valid sample duplicate로 group size 복원, 아니면 group 전체 discard

4.2.2 Multi-Teacher On-Policy Distillation (MOPD)

목적: 12개 specialist teacher (reasoning: math/STEM/code; agents & tools: coding, single/multi-workspace, search; preference & alignment: instruction following, human pref, safety, abstention) → 1개 student로 consolidation. 각 teacher는 own domain peak하지만 balanced/deployable 아님.

Naive SFT distillation의 실패 이유: (1) Off-policy — student가 teacher-generated trace에서 학습하나 자신의 error-compounded states에는 supervision 부재 (exposure bias), (2) 모든 domain을 한꺼번에 시키면 이 mismatch가 극심.

MOPD 설정:

  • Prompt마다 12명 중 정확히 1명에게 route
  • Student가 자신의 own trajectory 생성 → routed teacher가 이 trajectory의 각 위치에서 own domain distribution으로 score
  • Per-position reverse KL (student → teacher) 를 full vocabulary에 대해 closed-form 계산. Mode-seeking KL이 student를 teacher의 high-confidence continuation에 집중시킴
  • Distillation KL이 유일한 training objective. Verifiable outcome reward는 추가하지 않음. 이유:
    • $G$ rollouts per prompt가 요구되지만 (group-relative advantage), consolidation은 1 rollout/prompt로 실행 (thoughput bottleneck 감소)
    • 각 specialist가 이미 verifiable-reward RL로 훈련됨 → reward가 distribution에 이미 implicit
    • Reward hacking surface 제거
    • Reward term의 headroom (specialist 초과 학습)을 의도적으로 포기 — 목표는 12명을 match, out-train이 아님

Scaling MOPD to 250B (4 system challenges):

  1. Teacher placement cost: Colocated placement는 매 step actor GPU에 CPU-pinned teacher pool hot-swap (offload student, forward teacher, onload, train) → teacher forward가 serial critical path. 해결: pool에 dedicated node 할당해 per-step teacher tax를 zero로 압축
  2. Dense signal without $[L \times V]$ blow-up: Exact objective는 196,608 vocab × response position L → microbatch당 26GB fp32. 해결: teacher가 pre-lm_head hidden states $[L \times H]$만 ship (H=4096, 48× smaller). Student가 1024-token tile at a time으로 logits rebuild + activation checkpointing → GPU peak 1.1GB single tile buffer
  3. Transport cost: 각 sample이 exactly 1 teacher로 route → total teacher compute $O(\text{batch})$ (teacher 수 independent). Sample index로 keyed cache. CP-aware transport: teacher의 CP rank $r$이 이미 student CP rank $r$과 match → CP all-gather 건너뛰기
  4. Teacher pool management: 12명의 250B teacher는 accelerator에 co-reside 불가. 1 GPU-resident + 12 CPU snapshots, routed teacher를 단일 GPU slot으로 on-demand swap. Micro-batch를 routed teacher별로 packing → consecutive micro-batch가 대개 resident teacher hit → swap cost amortized

비판적 분석 (Critical Analysis)

강점

  • 1M-context를 목표로 architected된 첫 open-weight 한국어 프론티어 모델: NoPE + negative eigenvalue linear + hybrid 3:1 ratio + softmax-first ordering이 각각 ablation으로 검증된 통합 설계. Kimi Linear/Qwen3.5의 L-L-L-S와 대비되는 S-L-L-L 순서 채택 근거 명시.
  • Selective weight transfer의 실용적 명료함: "2.3% 파라미터가 shared skeleton"이라는 관찰과 1.7× 토큰 절감. Random init 대비 gap이 loss가 깊어질수록 확대되는 pattern은 후속 스케일업 프로젝트에 실용 지침. 다른 recent 대형 hybrid (Kimi Team, Qwen Team, MiniMax)가 모두 from-scratch였는데 이 논문이 partial warm start의 첫 실증.
  • MOPD의 시스템-수준 완성도: KL-only objective로 reward hacking 회피 + 4가지 system challenge (placement, dense signal blow-up, transport, pool management)를 정면으로 해결. Full-vocab KL을 26GB → 1.1GB per microbatch로 줄이는 tile-wise logit rebuild가 실용 기여.
  • Fully async RL 인프라의 5-component 통합: 특히 fresh-token-fraction gateway가 long tail trajectory salvage 문제를 우아하게 해결. Length/staleness-aware sampling도 startup length bias 문제를 명확히 정의하고 해결.
  • Ko-GDPval 86.8 (DeepSeek-V4-Pro 1.6T와 사실상 tie): 250B 크기로 6.4× 큰 모델과 동률. Sovereign AI의 실제 배포 목표 (문서 생산 officework agent) 달성 검증.
  • Data recipe ablation의 clean 비교: Same architecture/compute에서 recipe만 다르게 → +0.216 en_code, +0.204 ko_math 등 명확한 attribution. Isolate 실험 설계 우수.
  • Agent scenario 파이프라인의 엔지니어링 완성도: OfficeVerse (132-cell matrix), verifier-first, world-grounded workspace synthesis, controlled obfuscation — 각 요소가 데이터 품질의 특정 pathology를 방어.

약점 및 한계

  • Terminal Bench Hard, SWE-Bench 3-15점 gap: MiMo-V2.5 (41.7) vs Solar Open 2 (28.3), DeepSeek-V4-Flash SWE 73.8 vs 70.4. Repository/terminal-level 소프트웨어 엔지니어링이 저자도 인정하는 localized gap.
  • BrowseComp 없음: 웹 검색 에이전트 벤치가 English suite에 없음 (SWE, terminal, APEX, MCP-Atlas, τ³만). BrowseComp를 평가하지 않은 이유 부재 → 웹 검색 태스크 성능 미검증.
  • Multimodal 부재: Text-only. VLM 확장 계획 미언급 (A.X K2는 명시). 문서 이미지 이해 등의 sovereign officework에도 큰 gap.
  • Solar Open 1과의 backbone 공유가 archi novelty 제약: 48 layer, hidden 4096, head dim 128 identical 유지가 selective transfer의 조건. 즉 backbone dimension을 자유롭게 재설계할 수 없는 path-dependent 접근. 완전히 새로운 세대에서는 이 이점 소멸.
  • NoPE의 1M 실증은 attention design 수준: 실제 1M-length benchmark 결과 부재 (RULER 등이 없음). NIAH나 long-context understanding 벤치가 있어야 1M context 주장이 empirically supported. Softmax quadratic layer가 12개 있어 1M 처리 시 real memory footprint 미명시.
  • MOPD의 teacher 훈련 비용 미공개: 12명 specialist 각각을 domain-specific SFT + RL로 훈련하는 예산이 상세하지 않음. Total post-training compute의 majority가 여기에 갈 가능성.
  • Base model 초기화 편향: Solar Open 1이 이미 존재해야 하는 접근. 처음부터 시작하는 다른 팀은 이 recipe 적용 어려움.
  • 재현 어려움: 12명 teacher pool, OfficeVerse pipeline, live transactional DB 시뮬레이터 등 heavy 데이터 인프라. HF weight 공개는 있지만 recipe reproduction은 큰 자원 요구.
  • KMMLU-Pro에서 DeepSeek-V4-Flash에 뒤짐 (78.4 vs 78.9): Korean 평균이 SOTA지만 개별 벤치에서 tie/loss 존재. 향후 개선 여지.

확장 가능성

  • Selective weight transfer는 모든 세대 간 architectural jump에 이식 가능. Attention 종류 변경 (dense → MoE, softmax → linear-hybrid) 시 shape-compatible portion만 transfer라는 원칙은 일반화 가능.
  • MOPD의 KL-only + tile-wise logit rebuild + on-demand teacher swap 파이프라인은 다른 multi-specialist consolidation 프로젝트 (multi-modal, multi-language)에 직접 이식 가능.
  • Fully async RL의 5-component 특히 fresh-token-fraction gateway는 long-tail rollout이 있는 모든 agentic RL 시스템 (Anthropic, OpenAI 사설 시스템) 유형에 매력적.
  • OfficeVerse 파이프라인 (11×12 matrix + world-grounded workspace)는 다른 언어/국가 sovereign AI 팀이 재사용 가능한 데이터 합성 프레임워크. 이 논문은 사실상 agentic training data 생성의 blueprint.
  • Hybrid 3:1 (S-L-L-L) NoPE 설계는 향후 프론티어 long-context 모델의 default 후보. Solar Open 2가 먼저 대규모로 검증한 것.

Key Takeaways

  • ##Hybrid 3:1 linear-softmax + NoPE + negative eigenvalue##가 1M context 도달의 실용적 recipe. Softmax layer의 exact global recall과 linear layer의 fixed-size recurrent state가 상보. 이 조합이 pure linear의 recall 한계와 pure softmax의 quadratic 비용을 동시에 회피.
  • Selective weight transfer의 실전 가치: 2.3% 파라미터 이식으로 same-loss 도달에 1.7× 토큰 절감. Loss가 깊어질수록 gap 확대. 세대 간 architectural jump에서 partial warm start가 default choice가 될 만한 발견.
  • ##MOPD의 KL-only + student self-rollout##이 SFT distillation의 off-policy 한계를 우회. 특히 어떤 reward도 추가하지 않는 원칙이 reward hacking을 제거하는 동시에 consolidation 목표 (match, not out-train)와 일관됨.
  • Fully async RL의 fresh-token-fraction gateway는 long-tail trajectory 문제의 표준적 해결책이 될 잠재력. Trajectory 전체를 버리는 대신 stale prefix mask + fresh tail 사용은 실용적 균형.
  • ##Sovereign AI의 실전 목표 (officework agent) 달성##: Ko-GDPval 86.8, 1.6T DeepSeek-V4-Pro와 tie. 6.4× 작은 모델로 프론티어 실용성 도달. GPT-5.4 mini/Claude Haiku 4.5 대비 큰 폭 우위. 한국어 문화적 맥락 (alignment/honesty/safety)에서 특히 강한 것은 tokenizer 효율 + Korean data curation의 통합 결과.
  • Data recipe만 개선해도 same-compute에서 en_code +21.6, ko_math +20.4 같은 큰 폭 개선 가능. What each token teaches의 중요성을 명료히 실증. Quality/rarity-aware curation은 architectural change보다도 큰 lever가 될 수 있음.
