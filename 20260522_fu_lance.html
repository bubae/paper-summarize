TL;DR

  • 문제: unified multimodal model(UMM, 이해+생성을 한 모델로)은 두 가지 근본 한계가 있다. (1) ##이해와 생성의 visual representation 요구가 본질적으로 다름## — 이해는 high-level semantic feature(language-aligned), 생성은 low-level continuous feature(texture·geometry·temporal 보존). (2) 대부분 모델이 ##task coverage가 좁음## — image-text 중심이고, editing·subject-driven generation·video 같은 task를 unified multi-task로 다루지 못하고 downstream fine-tuning으로 처리.
  • 해결: ##Lance## — image+video의 understanding·generation·editing을 ##단일 native unified model##로. 두 원칙: ##(1) unified context learning(interleaved multimodal sequence로 cross-task 상호작용) + (2) decoupled capability pathways(이해·생성을 별도 expert로 분리)##. ##dual-stream Mixture-of-Experts##(LLM_UND + LLM_GEN)가 같은 shared context를 공유하되 별도 파라미터로 처리.
  • 왜 작동하는가: 이해와 생성을 한 backbone에서 경쟁시키지 않고(decoupled expert) 같은 sequence를 보게 하여(shared context) ##multi-task synergy##를 얻는다. ##multi-task가 단순 capability 합산이 아니라 cross-modality·cross-task transfer를 촉진## — 놀랍게도 multi-task generation 데이터가 video understanding까지 향상시킨다.
  • 비유: 한 사람이 ##'그림 감상'(이해)과 '그림 그리기'(생성)##를 모두 배우되, 두 능력에 ##별도의 전문 두뇌 영역##을 할당하고(decoupled), 같은 작업실(shared context)에서 훈련시킨다. 감상 연습이 그리기를, 그리기 연습이 감상을 서로 도와준다.

핵심 기여 (Key Contributions)

  1. Lance — native unified multimodal model: ##image/video understanding·generation·editing의 full spectrum을 단일 모델##로 지원. X2T(any-to-text), X2I(any-to-image), X2V(any-to-video) task family를 unified framework에서. multi-task synergy를 capability aggregation이 아니라 ##cross modality-task transfer 메커니즘##으로 봄.
  2. Dual-stream Mixture-of-Experts 아키텍처: ##shared interleaved multimodal sequence##를 보존하면서, understanding(LLM_UND)과 generation(LLM_GEN)에 ##dedicated visual representation·model capacity## 할당. understanding은 autoregressive next-token prediction, generation은 flow matching(velocity prediction).
  3. Modality-aware Rotary Positional Encoding (MaPE): heterogeneous visual token group(ViT semantic / clean VAE / noisy VAE)을 ##temporal 차원에 modality offset $\Delta_t$를 주입##하여 positional space에서 구분. spatial layout은 보존하면서 functional boundary를 명확화.
  4. Staged multi-task training paradigm: ##PT → CT → SFT → RL## 4단계. capability-oriented objective + adaptive data scheduling. RL 단계에서 GRPO + PaddleOCR reward로 text rendering·image-text correspondence 강화.
  5. 강력한 효율성: ##단 3B activated parameters + 128-GPU training budget##으로 open-source unified model 중 최상위 — GenEval 0.90, VBench 85.11, GEdit 7.30, MVBench 62.0. 7B~100B+ unified model을 능가.

배경 (Background)

Unified Multimodal Model(UMM)의 두 갈래와 한계

multimodal AI는 understanding·reasoning·generation을 single framework에 통합하는 native unified paradigm으로 이동 중이다. 기존 UMM은 두 갈래로 나뉜다:

  • Fully autoregressive (AR): Chameleon, Emu3, TokenFlow, HunyuanImage 3.0. understanding·generation을 shared token space의 next-token prediction으로. clean unified interface이나 ##reasoning 능력·visual fidelity·generation efficiency에서 trade-off##.
  • AR-diffusion hybrid: text는 language modeling, visual은 diffusion/flow-based. Transfusion, Show-o/Show-o2, BLIP3-o, BAGEL. 최근 ##decoupling 탐색## — Janus(visual encoding 분리), BAGEL(shared decoder-only backbone 하에서 expert specialization), TUNA(unified continuous representation), InternVL-U(강력한 MLLM + generation head).

두 가지 핵심 representation 결정

Lance의 design motivation은 두 관찰에 기반한다:

  1. Unified vs Decoupled Visual Representation: understanding은 language-aligned high-level semantic feature(SigLIP 2, Qwen2.5-VL ViT)에서, generation은 appearance·spatiotemporal structure를 보존하는 low-level latent에서 이득. 일부 연구(TUNA)는 shared representation을 탐색했으나 ##semantic reasoning과 high-fidelity synthesis를 동시에 만족시키기엔 부족##. → Lance는 semantic visual token과 generative latent token을 ##decoupled##하되 shared interleaved sequence 안에 조직.
  2. Shared Backbone vs Specialized Expert: single stream의 fully shared backbone은 clean하나 ##understanding과 generation이 substantially 다른 objective 하에서 같은 파라미터를 두고 경쟁##. BAGEL·HunyuanImage 3.0의 증거는 ##generation-oriented vs understanding-oriented 파라미터를 decouple하면 dense shared backbone 대비 명확한 이득##. → Lance는 unified multimodal token interface(bottleneck-free context fusion)는 보존하되 ##understanding·generation pathway에 specialized expert capacity## 할당.

방법론 (Methodology)

3.1 설계 원칙: unified context learning + decoupled capability pathways

Lance의 핵심: broad multi-task learning이 unified model의 잠재력을 더 끌어낼 수 있으나, ##task family마다(understanding/generation/editing) objective·representation·optimization dynamics가 크게 다름##. 효과적 unified model은 ##(1) 다른 task가 unified context learning 안에서 상호작용하게 하면서, (2) heterogeneous objective 간 간섭을 decoupled capability pathway로 완화##해야 한다.

3.2 전체 아키텍처

[입력] Text(Caption/VQA/OCR..) · Image(T2I/I2I/S2I..) · Video(T2V/I2V/V2V..) ↓ ↓ ↓ [Text Tokenizer] [ViT Encoder] [VAE Encoder] └──────────── MaPE (Modality-aware Rotary Positional Encoding) ────────────┘ ↓ [ LANCE: dual-expert backbone, generalized 3D causal attention ] ↙ (LLM_UND) ↘ (LLM_GEN) [Next-token Prediction] [Velocity Prediction] (ViT semantic + text tokens) (clean VAE + noisy VAE tokens)

Unified Context Learning: heterogeneous 입력을 shared interleaved multimodal sequence로 변환.

  • Text: Qwen2.5-VL의 language embedding layer로 embed.
  • Understanding-oriented visual: ##Qwen2.5-VL ViT encoder##(14× spatial / 2× temporal patching + 2×2 spatial merge)로 compact semantic visual token. language-aligned semantics 제공.
  • Generation-oriented visual: ##Wan2.2 3D causal VAE encoder##로 continuous latent(16× spatial downsampling, 4× temporal downsampling for video). low-level appearance·temporal structure 보존, lightweight MLP connector로 generation backbone hidden space에 projection.

각 sample은 unified interleaved sequence로 표현 (식 1–2):

$$\mathcal{S} = \cdots \oplus \mathcal{B}_{\text{text}}(\mathbf{T}) \oplus \mathcal{B}_{\text{vis}}(\mathbf{V}_{\text{vit}}) \oplus \mathcal{B}_{\text{vis}}(\mathbf{V}_{\text{vae}}^{\text{clean}}) \oplus \mathcal{B}_{\text{vis}}(\mathbf{V}_{\text{vae}}^{\text{noisy}}) \oplus \mathcal{B}_{\text{text}}(\mathbf{T}') \oplus \cdots$$

$$\mathcal{B}_{\text{text}}(\mathbf{T}) = [\texttt{BOT}, \mathbf{T}, \texttt{EOT}], \quad \mathcal{B}_{\text{vis}}(\mathbf{V}) = [\texttt{BOV}, \mathbf{V}, \texttt{EOV}]$$

직관적으로 말하면, 텍스트·의미 시각토큰·생성용 시각토큰을 모두 하나의 긴 sequence에 섞어 놓되, 각 modality를 special token(BOT/EOT, BOV/EOV)으로 경계 짓는다. generalized 3D causal attention: sequence를 modality-specific segment로 분할, 각 segment는 선행 segment에 attend(causal dependency 보존). segment 내부에서 ##text token은 causal attention, visual token은 bidirectional attention##(spatial·spatiotemporal structure 포착).

Decoupled Capability Pathways: 모든 modality를 shared sequence에 조직하되, understanding·generation을 specialized expert pathway로 처리.

  • Understanding expert $\text{LLM}_{\text{UND}}$: text token + semantic visual token에 작동, target text token을 autoregressive 예측. standard next-token prediction loss (식 3): $$\mathcal{L}_{\text{UND}} = -\sum_i \log p_{\theta_{\text{UND}}}(y_i \mid y_{<i}, \mathcal{S})$$
  • Generation expert $\text{LLM}_{\text{GEN}}$: VAE latent token에 작동, interleaved context 조건으로 generation-side hidden state 예측. clean latent $x_1$, noise $x_0 \sim \mathcal{N}(0,I)$, interpolated latent $x_t = t x_1 + (1-t) x_0$ ($t \sim \mathcal{U}(0,1)$). flow matching objective (식 4): $$\mathcal{L}_{\text{GEN}} = \mathbb{E}_{x_0, x_1, t}\left[\|v_{\theta_{\text{GEN}}}(x_t, \mathcal{S}, t) - (x_1 - x_0)\|_2^2\right]$$

직관: understanding expert는 "다음 단어 맞히기"로, generation expert는 "noise에서 clean image로 가는 속도 벡터(velocity) 맞히기"(flow matching)로 학습한다. 전체 목적함수 (식 5): $\mathcal{L} = \lambda_u \mathcal{L}_{\text{UND}} + \lambda_g \mathcal{L}_{\text{GEN}}$.

3.3 Modality-Aware Rotary Positional Encoding (MaPE)

unified multimodal training에서는 single sequence가 ##여러 visual token group($\mathbf{V}_{\text{vae}}^{\text{noisy}}, \mathbf{V}_{\text{vit}}, \mathbf{V}_{\text{vae}}^{\text{clean}}$)##을 포함한다. 이들은 source encoder뿐 아니라 functional role도 다르다(semantic cue / visual condition / generation target). 표준 3D-RoPE는 spatiotemporal layout만 encode하므로 이들을 구분 못 해 ##positional ambiguity##와 cross-task alignment 약화 유발.

Qwen2.5-VL의 원래 3D-RoPE에서 시각 토큰 $(t,h,w)$의 위치 (식 6): $\hat{\mathbf{p}}^{\text{vis}}_{t,h,w} = D + [t, h, w] = [D+t, D+h, D+w]$, $t \in [0,T-1], h \in [0,H-1], w \in [0,W-1]$.

MaPE는 ##각 modality group $m_i$의 index $i$에 따라 temporal 차원에만 fixed offset $\Delta_t$를 적용## (식 7):

$$\mathbf{p}^{(m_i)}_{t,h,w} = \hat{\mathbf{p}}^{(m_i)}_{t,h,w} + [i \cdot \Delta_t, 0, 0] = [\hat{t}^{(m_i)}_{t,h,w} + i\cdot\Delta_t,\ \hat{h}^{(m_i)}_{t,h,w},\ \hat{w}^{(m_i)}_{t,h,w}],\quad i \in \{0,1,2\}$$

직관: 세 종류의 시각 토큰 그룹을 ##시간축에서 서로 다른 출발점($i\cdot\Delta_t$)에 배치##하여 "이건 의미용, 이건 조건용, 이건 생성 타깃"임을 위치 정보로 명시한다. spatial 좌표는 그대로 두어 image/video의 intrinsic layout과 temporal order·상대 거리를 보존. $\Delta_t = 1000$으로 설정.

  • SFT: high-quality·task-aligned supervision으로 refine. instruction fidelity·visual consistency·editing accuracy·identity preservation 강조. 190K high-quality image caption, 190K image generation, 84K image editing, 5K/9K/5.5K video 등.
  • RL: image generation 능력을 task-specific reward로 직접 최적화. ##GRPO(Group Relative Policy Optimization)##로 fine-grained textual constraint 만족 유도. ##20K image generation prompts##, ##PaddleOCR을 reward model##로 사용해 생성 이미지와 텍스트 제약의 consistency 평가(text rendering·image-text alignment). supervised fine-tuning만으로 잡기 어려운 측면에 직접 피드백.

Task-specific system prompt(Figure 8–9)로 unified context 내 heterogeneous task 구분(I2T/V2T captioning, T2I/T2V generation, X2I/X2V editing 등 별도 prompt template).

실험 (Experiments)

Lance는 ##Qwen2.5-VL 3B## 위에 구현(visual understanding encoder + LLM_UND/LLM_GEN backbone 초기화). 각 attention block에 QK-Norm 장착(초기화 backbone의 query-key activation 분포 변경 → 직접 재사용이 아니라 staged training으로 re-adapt). visual generation은 Wan2.2 3D causal VAE. CFG(classifier-free guidance) 적용(PT에서 text condition 10% drop, CT/SFT에서 full condition 5% drop + text-only 5% drop). inference: image 768×768, video 480p 12fps, text CFG scale 4.

5.2.1 Image Generation

실험 의도: 3B unified model이 훨씬 큰 generation-only/unified model과 경쟁 가능한가? 결과(Table 5): GenEval ##overall 0.90##(unified model 중 best와 동률, counting 0.84·colors 0.97·position 0.87·attr 0.81에서 강함). DPG-Bench overall 84.67(relation modeling 93.38에서 특히 우수). 뒷받침: 단 3B activated param으로 7B BAGEL(0.80)·1.7B InternVL-U(0.85)·20B Qwen-Image(0.87)를 능가 → unified framework가 high-quality image synthesis를 효율적으로 지원.

5.2.2 Video Generation

결과(Table 6, VBench): ##Total Score 85.11## — unified model 중 best, 3B activated param으로. quality·semantic 양면에서 강함(Multi-Objects 93.86, Human Action 97.80, Spatial Relation 93.61, Temporal Flickering 99.66). 8.3B HunyuanVideo1.5·5B Wan2.2·7B UniVideo와 정성 비교에서 complex human interaction("two adults hugging")·explicit camera transition("medium view → close facial framing")을 정확히 따름. 뒷받침: unified framework가 image→video로 자연스럽게 scaling, compositional video generation·text-video alignment 지원.

5.2.3 Multimodal Editing

결과(Table 7, GEdit-Bench): ##Avg/G_O 7.30## — unified model 중 best. background change·material modification·motion change·portrait beautification·subject removal·replacement·tone change에서 best. ##단, text modification은 상대적 약점##(향후 개선 방향). image+video editing 모두 정성적으로 구조 보존·자연스러운 motion dynamics.

5.2.4 Multimodal Understanding

결과(Table 8, MVBench): ##Overall 62.0## — 기존 unified model 중 best, second-best unified(Show-o2 7B 50.6) 대비 ##~11.3% relative 향상##. ##절반 이하 파라미터로## 강한 video understanding 유지. unified multi-task training이 generation·editing을 가능케 하면서도 강한 understanding을 보존함을 시사.

비판적 분석 (Critical Analysis)

  • 효율성 주장의 미묘함 — "3B activated parameters": Lance는 3B activated param을 강조하나, ##dual-stream MoE이므로 total parameter는 더 크다##(LLM_UND + LLM_GEN). 또한 Qwen2.5-VL 3B + Wan2.2 VAE + ViT encoder를 합치면 실제 model footprint·storage·serving cost는 "3B"가 시사하는 것보다 크다. "128-GPU budget"도 절대 작은 자원이 아니다. 효율성 비교가 activated param 기준이라 ##공정성에 주의##가 필요하다.
  • Baseline 비교의 공정성: GenEval 0.90이 "unified model 중 best와 동률"인데, 일부 baseline은 LLM rewriter 사용(†표시), Lance도 video에서 LLM rewriter 사용(†). prompt rewriting 유무가 점수에 큰 영향을 줄 수 있어 ##rewriter 조건을 통제한 비교가 더 명확##했을 것이다.
  • Text rendering 약점: 저자도 인정하듯 ##image editing의 text modification이 약점##이고, RL 단계에서 PaddleOCR reward로 text rendering을 보강해야 했다. 이는 unified model에서 ##fine-grained text 일관성이 여전히 미해결##임을 보여주는 동시에, dedicated text-rendering 데이터 부재(저자가 future work로 명시)라는 데이터 한계를 드러낸다.
  • Ablation scale의 제약: cross-task synergy ablation(Table 9)이 ##GenEval 80~82, VBench 81~83 범위의 작은 차이(1~2점)##로 결론을 내린다. seed variance·통계적 유의성 보고가 없어, "multi-task가 video understanding을 향상"이라는 surprising claim(58.06→59.18, +1.1점)이 ##noise 대비 robust한지 불확실##.
  • MaPE의 일반성: MaPE는 Qwen2.5-VL의 3D-RoPE에 특화된 modification으로, 효과(특히 editing +0.56)는 명확하나 ##다른 backbone·다른 token grouping에 일반화되는지##는 검증되지 않았다. $\Delta_t=1000$이라는 hyperparameter 선택의 sensitivity도 보고되지 않음.
  • Native vs initialized의 모호함: "trained from scratch"(abstract)라 하면서도 실제로는 ##Qwen2.5-VL 3B weights로 initialize##(§5.1). QK-Norm으로 인해 "직접 재사용이 아니라 re-adapt"라 설명하나, "native unified / from scratch"라는 표현과 pretrained backbone 초기화 사이에 ##수사적 긴장##이 있다.

이 논문에서 가져갈 것 (Key Takeaways)

  • "Shared context + Decoupled experts"는 강력한 unified design 패턴: 이해와 생성을 한 backbone에서 경쟁시키지 말되, 같은 interleaved sequence를 보게 하라. 간섭은 줄이고 transfer는 살린다. 향후 unified multimodal 설계의 참고 청사진.
  • Multi-task synergy의 실증: multi-task 데이터가 단순 능력 누적이 아니라 ##cross-task로 전이##된다는 증거(multi-task generation 데이터가 video understanding까지 향상). 데이터 믹스를 task별 silo가 아니라 synergy 관점에서 설계할 동기.
  • Heterogeneous token에는 positional 신호로 역할을 명시하라: MaPE처럼 token group을 positional space에서 구분하면 특히 ##editing(condition+target 동시 추론)##에서 이득. 여러 종류의 visual token을 한 sequence에 섞는 모든 아키텍처에 적용 가능한 아이디어.
  • 효율적 unified model의 가능성: 3B activated param + 128 GPU로 7B~20B 모델과 경쟁 → unified multimodal이 ##반드시 초거대 모델일 필요는 없다##는 실용적 신호. 리소스 제약 환경의 참고점.
  • RL로 fine-grained 제약 보강: text rendering·image-text alignment 같이 SFT로 잡기 어려운 측면은 ##GRPO + 외부 reward model(PaddleOCR)##로 보강하는 실용적 recipe.
  • 비판적 독해: "3B"·"from scratch"·"best among unified" 같은 표현은 activated param 기준·pretrained 초기화·rewriter 조건 등 ##세부 조건을 확인##하고 받아들일 것.
