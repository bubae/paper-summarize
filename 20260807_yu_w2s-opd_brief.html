왜 W2S-OPD가 필요한가

Strong-to-Weak OPD의 한계

Qwen3, Gemma 등은 더 큰 teacher(235B)에서 8B로 distill. 하지만 frontier 모델은 더 큰 teacher가 없다. Performance ceiling.

Same-Origin Consolidation의 비용

MOPD, DeepSeek-V4는 여러 domain expert를 student scale로 학습 후 병합. Student scale RL은 극도로 비싸다.

제3의 길: Weak-to-Strong

이미 존재하거나 저비용으로 얻을 수 있는 약한 supervision source로 강한 student를 개선. 그러나 direct application은 (1) distributional mismatch, (2) teacher ceiling에 걸린다.

W2S-OPD의 해답: 약한 모델을 imitate하지 않고, 두 약한 모델의 capability direction만 뽑아 student의 base에 anchoring.

W2S-OPD Framework (Figure 2 재현)

Figure 2 재현: (좌) 두 weak model이 logit 차이 z⁺−z⁻ 생성. (중) student base logits에 α배로 얹어 proxy teacher π_T,α 합성. Student는 자신의 on-policy rollout에서 이 proxy teacher에 대한 KL을 최소화. (우) 세 종류의 contrast pair.

수식 요약

Proxy Teacher (수식 2)

π_T,α(·|s_t) = softmax(z_base + α · (z⁺ − z⁻))

Base logit을 anchor로 하고 capability direction만 α배로 얹는다. α=0이면 student base 자체.

W2S-OPD Loss (수식 3)

L = E[Σ_t KL(π_S(·|s_t) ‖ π_T,α(·|s_t))]

Student의 rollout에서 per-token reverse KL. On-policy 이점 그대로.

Trust-region 해석 (수식 10)

W2S-OPD의 proxy teacher는 KL-constrained reward maximization의 closed-form 해:

π_T,α = argmax {E_q[r(s,a)] − (1/α)·KL(q ‖ π_base)}

여기서 r(s,a) = log π⁺ − log π⁻. Ad hoc heuristic이 아니라 정확한 objective.

Product-of-Experts 관점 (수식 11)

π_T,α(a|s) ∝ π_base(a|s) · (π⁺(a|s)/π⁻(a|s))^α

Base가 anchor, π⁺가 conjoined expert, π⁻가 negated expert. Decoding-time composition을 학습 signal로 재해석.

핵심 관찰

모든 인스턴스에서 m⁺와 m⁻ 둘 다 student(8B)보다 작다. 그럼에도 그들의 차이(direction)가 student를 improvement 방향으로 유도한다. 이것이 weak-to-strong의 핵심 기적.

Plan 15.7% (baseline 8.6%), Monitor 1.8% (0.5%). Reasoning framework 강화 — 문제를 구조화하고 궤적을 감시.

한계점

α의 domain-dependent 튜닝

Math는 α=1.25~1.5, code는 α=0.75~1.0이 최적. 새 도메인마다 sweep 필요. 자동 결정 방법 부재.

Direct-OPD와 명시적 비교 부재

Concurrent work Direct-OPD (Feng et al., 2026)와 개념적으로 유사하나 실험 비교 없음. 정확한 우위폭 불명.

Hint contrast의 marginal gain

Math +1.4, Code +1.1로 다른 setting보다 확실히 작음. Single-model contrast의 실용 가치 제한.

학생 크기가 하나만

Qwen3-8B로만 검증. Frontier scale(70B+, 400B+)에서 동일 gain 나오는지 미확인.

Thinking mode 미검증

Non-thinking mode로만 실험. Thinking mode에서 CoT 궤적이 훨씬 긴데 프레임워크가 그대로 확장되는지 불명.

한 줄 결론

"강한 teacher가 없어도 두 약한 모델의 capability direction으로 frontier 모델을 개선할 수 있다. Distillation은 imitation이 아니라 directional engineering이다."
