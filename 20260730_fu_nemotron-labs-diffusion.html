TL;DR

  • 문제: Autoregressive (AR) 언어 모델은 배치 크기 1 서빙에서 병렬성을 활용하지 못하고, 순수 diffusion LM은 AR 대비 정확도와 학습 효율에서 뒤처진다. 기존 Multi-Token Prediction (MTP) 방식의 speculative decoding은 draft head가 짧은 horizon만 예측 가능하고 auxiliary head 오버헤드가 있다. AR과 diffusion을 경쟁하는 패러다임이 아니라 보완적으로 결합할 수 있는가?
  • 해결: 하나의 아키텍처에 AR loss + block-wise diffusion loss를 joint objective로 학습해, 추론 시 (1) 순수 AR, (2) 순수 diffusion, (3) diffusion draft + AR verify의 self-speculation, 세 가지 모드를 모두 지원하는 tri-mode LM을 구축. Ministral3-8B에서 시작해 3B/8B/14B로 스케일링, VLM 변형까지 릴리스.
  • 왜 작동하는가: AR objective가 left-to-right linguistic prior와 planning 능력을 앵커링하고, diffusion objective가 lookahead (미래 예측) 병렬성을 부여한다. 두 loss는 $\alpha=0.3$ 조합에서 서로 경쟁하지 않고 상호 강화: AR-only 대비 diffusion loss 추가가 AR 정확도를 유지/미세 향상시키고, diffusion-only 대비 AR loss 추가는 diffusion 정확도를 +7.48% 향상.
  • 비유: "왼손잡이/오른손잡이 중 하나가 아니라, 양손잡이로 훈련하면 오히려 각 손 능력이 더 좋아진다." 왼손(AR)이 문법의 뼈대를 잡고, 오른손(diffusion)이 미래를 미리 그려보며, 검증할 때는 두 손이 서로를 점검한다.

핵심 기여 (Key Contributions)

  1. Tri-mode LM 프레임워크: AR + block-wise diffusion joint training으로 하나의 모델에서 3가지 추론 모드를 모두 지원. 배포 환경 (concurrency level) 에 따라 자유로운 모드 전환.
  2. AR과 diffusion의 상호 보완성 실증: ##$\alpha=0.3$ (diffusion loss 계수)에서 두 objective가 서로 hurt하지 않고 오히려 함께 상승하는 sweet spot 존재##. Table 2·3에서 diffusion loss 추가가 AR 정확도를 +0.14% (base) / +0.43% (instruct) 유지·향상.
  3. Self-speculation이 MTP를 지배: Diffusion draft + AR verify가 Eagle3 (MTP) 대비 더 높은 acceptance length (native/LoRA 5.46/6.82 vs. Eagle3/MTP 2.75/4.24, ~2× 이상)와 real-device 효율 달성. Auxiliary head 오버헤드 제거.
  4. Speed-of-Light (SOL) 분석: Diffusion 모드가 최적 sampler 하에 self-speculation 대비 76.5% 더 많은 토큰을 forward pass당 예측할 수 있음. 즉 현재 confidence-based sampling이 상한 대비 상당히 sub-optimal.
  5. Nemotron-Labs-Diffusion 모델 패밀리 공개: 3B/8B/14B base + instruct + VLM. Nemotron-Labs-Diffusion-8B가 Qwen3-8B 대비 6× TPF, GB200에서 4× system throughput (SPEED-Bench + SGLang, 다양한 concurrency); batch=1 concurrency에서는 3.3× (optimized kernel 시 3.97×, 1015 tok/sec). VLM은 LLaDA-V-8B 대비 6.03× TPF (linear self-spec, 응답 >100 토큰).

배경 지식 (Background)

Autoregressive vs. Diffusion vs. MTP

AR은 다음 토큰 조건부 확률 $p_\theta(x_i | x_{

Discrete diffusion (masked)은 시퀀스를 마스킹하고 병렬로 복원. Block-wise diffusion (Arriola et al., 2025a)은 블록 단위 AR + 블록 내부 병렬로 KV 캐시 지원.

MTP (Multi-Token Prediction)는 Eagle3처럼 작은 draft head가 여러 미래 토큰을 예측하고, 큰 AR 모델이 검증. 두 병목: (a) draft head 용량 제한으로 short horizon만 신뢰 가능, (b) proposal이 recursive해 각 단계마다 embedding + LM head 비용 발생.

Speed-of-Light (SOL) 개념

SOL은 diffusion 모드의 내재적 병렬성 상한을 측정. 즉 AR verifier 개입 없이, diffusion 모델 자신이 이상적 sampler로 forward pass당 얼마나 많은 정확한 토큰을 예측할 수 있는가. 현재 sampler(confidence threshold) 대비 SOL이 얼마나 여유가 있는지를 정량화해, 향후 sampler 개선의 헤드룸을 보여줌.

방법론 (Methodology)

2. Tri-Mode LM Training

2.1 Joint Objective

총 loss는 AR loss (계수 1)와 diffusion loss ($\alpha$)의 가중합:

$$\mathcal{L}(\theta) = \mathcal{L}_{\text{AR}}(\theta) + \alpha\, \mathcal{L}_{\text{diff}}(\theta), \quad \alpha = 0.3.$$

Diffusion loss가 AR loss보다 typically 크므로 $\alpha < 1$로 magnitude를 정렬. $\alpha=0.3$에서 두 loss가 harmonize.

Two-stage training: 초기에는 $\alpha=0$ (pure AR objective)로 left-to-right inductive bias를 앵커링, 이후 $\alpha=0.3$로 diffusion 감독을 켜서 두 loss를 함께 최적화. 이는 diffusion gradient가 AR prior를 덮어쓰지 않고 보완하도록 유도.

2.2 Attention Pattern

Dual-stream 입력: corrupted/noisy view $\tilde{x}$ + clean view $x$를 concat. Attention은 4개 영역:

  • Noisy→Noisy: block-diagonal (블록 내부 bidirectional)
  • Noisy→Clean: causal across blocks (denoise 시 prefix clean 참조)
  • Clean→Clean: ##strictly causal## — Fast-dVLM와 동일 철학. 이를 통해 AR objective를 clean stream에 계산하고 diffusion을 noisy stream에 계산해 단일 forward-backward pass에서 두 objective 동시 학습 가능.

Global Loss Averaging: 각 시퀀스의 loss를 평균한 뒤 배치 평균 (Eq. 4)이 아니라, 전체 배치 $NL$ 토큰을 균등하게 평균 (Eq. 5):

$$\mathcal{L}_{\text{global}} = \frac{1}{NL}\sum_{n=1}^{N}\sum_{i=1}^{L}\ell_{n,i}.$$

직관적으로 말하면, diffusion에서는 sample마다 마스킹된 토큰 수가 다르고 $\frac{1}{t}$ reweighting까지 있어 특정 sample이 배치를 지배하기 쉬움. Global averaging은 이를 방지해 gradient variance 감소. RL에서 GRPO vs. DAPO의 aggregation 선택과 유사한 문제.

DP-rank Varying Masking Ratios: 서로 다른 data-parallel rank가 서로 다른 noise level로 학습하도록 해 sample 다양성 증가.

Two-stage training: AR-only initialization으로 시작 → +5.74% 큰 개선. 강한 AR 초기화가 AR→diffusion 변환을 훨씬 easier하게 함.

AR loss 추가 (전체 파이프라인 완성): 단일 최대 개선 +7.48%. 이는 diffusion training 중 AR objective 유지가 정확도의 핵심 요인임을 확증.

3. Tri-Mode Inference

3.1 Mode 1: AR Decoding

표준 left-to-right sampling. High concurrency (compute-bound) serving에 최적.

3.2 Mode 2: Block-wise Diffusion Denoising

Confidence-based sampling: 각 스텝에서 신뢰도 임계값을 넘는 모든 위치를 커밋. 임계값 튜닝이 인퍼런스 시 accuracy-TPF tradeoff를 조절.

Trained sampler: 고정 임계값은 optimal이 아니므로, 4-layer Transformer sampler (∼4.8M params, ~0.06% of 8B backbone)를 별도로 학습. 입력 feature 144-D: PCA-compressed top-3 semantic embeddings + output statistics (top-1 prob, margin, top-3 mass, entropy). Bidirectional over current block + per-position linear head with sigmoid.

학습: Nemotron-Labs-Diffusion-8B에서 ∼20M denoising trajectories 수집 (math/code/STEM/chat), block length 8/32. 두 정책 혼합: (i) 표준 confidence order (k=1), (ii) ground-truth top-1 pre-commit + confidence fallback. Per-position binary cross-entropy on masked positions.

Cross-position attention의 중요성 (Appendix A): Sampler에서 cross-position attention을 제거하고 MLP-only로 변경 시 held-out trajectory의 accuracy-TPF AUC가 10pp 저하. 즉 sampler가 어떤 위치들이 서로 안전하게 커밋될 수 있는지 공동 추론해야 함을 시사.

3.3 Mode 3: Self-Speculation Decoding

Linear self-speculation: k개의 mask token을 verified prefix에 append. Diffusion pathway로 모든 k 위치를 병렬로 denoise해 $\{\hat{x}_{n+1}, \ldots, \hat{x}_{n+k}\}$ draft 생성. 이후 같은 모델의 causal attention을 재사용해 두 번째 forward pass로 검증. 첫 mismatch까지의 longest prefix를 accept + AR prediction 1 토큰 추가 → 스텝당 1~k+1 토큰.

LoRA-Enhanced Linear SS: LoRA (rank 128, α=512, ∼36M params, ~0.4% of backbone) — attention의 $o_{\text{proj}}$ layer에만 적용, diffusion pathway drafter에만 tune. AR verifier는 unchanged. Draft를 verifier에 better align해 acceptance length 확장.

Drafter loss: LK-hybrid distribution matching + token-level cross-entropy on accepted prefix + first rejected position. Active position mask ("accepted+1")를 통해 rejection 이후 위치는 loss에서 제외. 이유: inference 시 rejection point에서 verifier의 KV cache가 재구축되므로, drafter가 counterfactual distribution으로 학습되면 실전과 mismatch 발생.

$$\mathcal{L}_j^{\text{LK}} = \lambda_j \cdot \text{KL}(\tilde{p}_j \| \tilde{q}_j) + (1-\lambda_j)\cdot\tfrac{1}{2}\sum_{v\in \mathcal{U}_j}\lvert\tilde{p}_j(v)-\tilde{q}_j(v)\rvert.$$

$\mathcal{U}_j = \mathcal{S}^t_j \cup \mathcal{S}^d_j$ (verifier + drafter 각각의 top-K 인덱스 합집합, K=200으로 $|\mathcal{U}_j|\leq 400$). Full-vocabulary KL의 catastrophe를 피함.

$$\lambda_j = \exp(-\eta \cdot |\alpha_j|), \quad \eta=0.5.$$

Adaptive coefficient: 학습 초기 ($\alpha_j \approx 0$, $\lambda_j \approx 1$)에는 forward KL처럼 작동해 distribution matching gradient 제공, drafter가 verifier에 접근함에 따라 ($\alpha_j \to 1$, $\lambda_j \to e^{-\eta} \approx 0.6$) TV로 전환해 acceptance-rate gap을 직접 최소화.

3.4 Variant: Quadratic Self-Speculation

Draft와 verification을 단일 forward pass로 fuse. 구조화된 attention mask로 causal predictions가 이전 draft를 검증하고, parallel diffusion predictions가 다음 iteration의 draft 생성. Interleaved quadratic layout: 각 iteration에서 verification이 조기 종료돼도 k개 speculative token을 일관되게 생성. 이론적 TPF 우수 ($O(B^2)$ 입력), 하지만 커널 미최적화로 real-device 효율은 linear에 밀림.

추론 모드별 배포 특성

고 concurrency (compute-bound): AR mode — 서버 batch 처리에 최적 저 concurrency (memory-bound): Self-speculation — 개별 사용자 저지연 Long-context bulk generation: Diffusion mode — 병렬성 극대화 (SOL 상한)

4. Speed-of-Light (SOL) Analysis

목적: Confidence-based sampling이 상한 대비 얼마나 sub-optimal한지, 그리고 diffusion 모드의 진정한 병렬성 잠재력이 얼마인지 측정.

4.1 Diffusion SOL 구성

Oracle target via serial denoising: 크기 $B$ 블록에 대해 all-mask 입력 $\mathbf{x}^{(0)} = [\text{M}]^B$에서 시작, 매 스텝마다 output distribution의 peak probability가 가장 높은 위치 하나만 커밋 (그 위치에 argmax 채우기). $B$번의 forward pass 후 완전 unmasked target $\mathbf{t}=(t_1,\ldots,t_B)$ 획득. 이것이 병렬 커밋 없이 diffusion 자신이 수렴하는 target.

Greedy parallel acceptance: 매 iteration에서 모델의 argmax가 target과 일치하는 모든 masked position을 한 번에 커밋. 다만 committed token 각각이 다음 forward의 context가 되므로, 여러 개를 한 번에 커밋하면 다른 위치의 분포를 target에서 멀어지게 할 수 있음.

Recursive dynamic compaction: Greedy 대신 safe prefix 탐색. 매 iteration에서 N matched position을 confidence order로 정렬 $(p_1,\ldots,p_N)$, 가장 긴 $\{p_1,\ldots,p_k\}$ 중 safe한 것 찾기. "Safe" = 남은 위치들이 여전히 $\mathbf{t}$로 수렴하는지 재귀적으로 확인 (스텝 5000 forward budget). Budget 초과 시 unsafe로 처리하고 binary search로 축소. Top-1 커밋은 항상 safe이므로 최소 1 토큰/iter는 보장.

Diffusion SOL vs. Linear Self-Speculation: 두 metric은 다른 것을 잰다. Acceptance rate 수준에서는 linear SS 6.82 vs. SOL 7.60 (10.3% gap, 근접). Real TPF에서는 SOL 6.02× vs. linear SS 3.41× (76.5% 갭). 이유: Linear SS는 두 forward per cycle 필요 + prefix-only acceptance. Diffusion mode는 단일 forward에서 non-contiguous position들도 커밋 가능.

이 실험이 뒷받침하는 주장: Diffusion decoding은 self-speculation보다 더 높은 병렬 상한을 갖고 있어, 미래에 더 좋은 sampler가 나오면 더 크게 확장 가능. 반면 self-speculation은 AR verify라는 fundamental bottleneck에 묶여있음.

5. Nemotron-Labs-Diffusion 모델 패밀리

5.1 Base Models

  • Ministral3-8B에서 시작, 25B pretraining data
  • Two-stage: Stage 1 pure AR (1T 토큰), Stage 2 joint AR+diffusion ($\alpha=0.3$, 300B 토큰)
  • Optimizer: AdamW, weight decay 0.1, WSD schedule (1e-5 → 3e-6), global batch 512, seq len 4096
  • Hardware: 256 NVIDIA H100
  • Megatron Bridge로 학습/추론 파이프라인 공개

5.2 Instruct Models

  • SFT on 45B tokens (dataset from Nemotron-Post-Training-Dataset-v2), $\alpha=0.3$ 유지
  • LR 2.5e-6 → 2.5e-7 WSD schedule, batch 256, seq len 16k
  • 256 H100, prompt 부분 mask 안 함, answer 부분에만 loss

5.3 Vision-Language Models

Architecture: Nemotron-Labs-Diffusion에 vision encoder + 2-layer MLP projector (2×2 patch merging) 추가. Text 모델과 diffusion 학습/추론 파이프라인 공유.

Weight initialization: LM backbone은 Nemotron-Labs-Diffusion-8B instruct에서, vision encoder + projector는 동일 계열 AR VLM (Ministral3-8B-Instruct-2512 기반)에서. LM architecture가 identical하므로 mismatch/interpolation 없음. 어휘/embedding 변경 없음.

Continued SFT: 전체 모델을 text-only instruct와 동일한 joint AR-diffusion objective로 multimodal instruction data에서 fine-tune.

Asymmetric dual-stream: Vision token은 절대 corrupt되지 않으므로 noisy stream에서 완전 제거. Loss 계산에 기여하지 않는데 FLOPs 소모하는 문제를 해결. 총 시퀀스 길이가 $2L$ → $L_{\text{text}} + L$로 감소 ($L_{\text{text}} = L - N_{\text{vis}}$). Attention FLOPs 감소가 vision token 비율 $N_{\text{vis}}/L$에 비례 (Fast-dVLM의 vision-efficient concatenation과 동일 원리).

관련 연구 (§7 Related Work)

Diffusion Language Models 계보: 초기 continuous LM (Diffusion-LM, DiffuSeq, SSD-LM) → 이산 masked diffusion (Austin et al. 2021, DiffusionBERT, SEDD, MDLM, SMDM) → 대규모 스케일링 (LLaDA 8B, Dream 7B, LLaDA2.0 100B). 도메인 특화 스페셜리스트 (Mercury 코딩, Seed Diffusion, DiffuCoder, Dream-Coder). RL 계열 확장 (d1, LLaDA 1.5), 멀티모달 확장 (MMaDA, LaViDa)도 활발.

Diffusion LM Acceleration 계보: (1) 캐싱 계열 (dLLM-cache, dKV-cache, Fast-dLLM v1) — bidirectional attention의 KV 재사용 근사. (2) Parallel decoding 개선 — confidence-based sampling, AR guidance (Israel et al.), certainty+positional prior (Wei et al.). (3) AR→diffusion 이니셜라이제이션 (SDAR, DiffuLLaMA) — 사전학습 AR을 diffusion으로 shift. (4) Block-wise 결합 — Block Diffusion (원조), TIDAR, EDiT, Fast-dLLM v2 등이 pretrained AR/diffusion을 block-wise로 변환. 본 논문의 tri-mode는 joint training과 self-speculation을 결합했다는 점에서 이 계보의 다음 단계.

저자 명시 인사이트 및 향후 방향 (§8)

6가지 핵심 인사이트

  1. Tri-mode generation naturally emerges from joint AR-diffusion training: 아키텍처 수정 없이도 세 가지 모드가 자동 확보.
  2. AR과 diffusion loss는 상호 보완적: $\alpha=0.3$에서 두 loss가 함께 peak. AR loss는 diffusion에 left-to-right prior를 주고, diffusion loss는 AR의 planning 능력을 향상.
  3. Self-speculation이 MTP를 능가: Auxiliary head 대신 diffusion으로 draft, AR로 검증 → 더 높은 acceptance rate, 더 나은 real-device 효율.
  4. Variance reduction은 diffusion training에 필수: Random masking + variable noise level로 인한 gradient variance를 well-trained AR 초기화 + global loss averaging으로 완화. 이것이 학습 안정성의 핵심.
  5. Linear self-speculation이 현재 인프라에서 최고 효율: Quadratic SS는 TPF 우수하나 커널 미비. Batch 1에서는 quadratic이 유망.
  6. Diffusion 모드에 substantial headroom: SOL 7.60× vs. real linear SS 3.41× → 더 나은 sampler로 76.5% 추가 개선 가능.

4가지 향후 방향

  1. SOL 상한과 실제 diffusion decoding 간격 좁히기: 더 잘 정렬된 sampler 개발, 혹은 conditionally independent token들의 aggressive parallel sampling.
  2. Self-speculation의 draft-verify 정렬 개선: 학습 시 diffusion draft를 AR verify에 align. Nested subnet (weight-shared smaller drafter)로 drafting cost 추가 절감.
  3. Prefix-only AR verification을 넘어서기: Diffusion verifier로 non-contiguous drafted token을 동시 검증해 real effective acceptance rate 상승.
  4. Diffusion generation의 higher-level parallelism: 현재 token-level만 병렬. Segment/paragraph-level parallelism을 학습으로 유도 → global planning + 효율 잠재력 극대화.

비판적 분석 (Critical Analysis)

강점

  • Tri-mode의 개념적 우아함과 실증적 강도: "AR과 diffusion 중 어느 것을 쓸까"라는 오래된 이분법을 "둘을 동시에 학습해 세 가지 모드로 배포"로 재프레이밍. 그리고 $\alpha=0.3$에서 두 loss가 상호 강화된다는 실험적 발견은 강력한 empirical support.
  • Ablation의 정밀함: 5단계 progressive addition (block-wise attention → global loss avg → DP-rank masking → two-stage → AR loss)이 각 컴포넌트의 기여를 명확히 분리. 특히 AR loss 추가가 +7.48%로 최대 개선이라는 발견은 diffusion LM 커뮤니티에 중요한 신호.
  • SOL 분석의 학술적 가치: Diffusion 모드의 이론적 상한을 recursive dynamic compaction으로 정량화한 것은 향후 sampler 연구의 방향성을 명확히 함. "현재 방식이 상한 대비 얼마나 남았는가"라는 질문을 formal하게 답한 것은 이 분야에서 드문 기여.
  • Self-speculation vs. MTP 헤드투헤드: LoRA-tuned Nemotron이 Eagle3/MTP를 acceptance length와 wall-clock에서 모두 이긴다는 결과는, diffusion drafting이 speculative decoding의 미래일 수 있음을 강력히 시사.
  • 모델 패밀리 공개 (3B/8B/14B + VLM): 재현/후속 연구가 즉시 가능. Megatron Bridge를 통한 학습/추론 파이프라인 공개.
  • Trained sampler와 LoRA drafter의 실용성: 두 컴포넌트 모두 backbone 대비 0.06%/0.4%의 오버헤드로, alignment 개선을 저비용에 실현.

약점 및 한계

  • SDAR-8B Chat과의 정확도 격차: Instruct 세팅에서 diffusion mode 63.18 vs. SDAR 54.09 (+9.09%)이지만, SDAR이 정확도를 위해 TPF 1×로 운영된 상태. TPF 매칭 비교가 없어 "같은 latency에서 얼마나 나은지"는 불명확.
  • Quadratic SS의 지속적 커널 병목: 이론적 TPF 우수 (6.38× vs. linear 5.99×)이지만 real-device는 linear에 밀림. Fast-dVLM과 동일한 이슈로, quadratic이 실용화되려면 여전히 커널 개발 필요.
  • Base model 초기화 편향: Ministral3-8B가 base였고, 다른 base (Llama, Qwen 등)에서 시작했을 때 tri-mode의 우수성이 유지되는지 검증 부재.
  • SOL의 실용 gap: SOL 7.60× vs. real linear SS 3.41× — 즉 더 나은 sampler가 나와야 이 논문이 시사하는 상한에 접근 가능. 저자는 이를 future work로 남기고 있으나, 현재 논문 자체는 sampler 개선을 완성하지 못함.
  • LoRA drafter 학습 비용: 정확한 학습 시간/데이터 크기 미명시. LoRA는 30-40% relative TPF 개선의 상당 부분을 제공하지만, 이를 얻기 위한 추가 학습 예산은 논문에서 상세 불명.
  • Multi-turn / long-context 검증 부족: SPEED-Bench는 주로 short-response. Multi-turn dialogue나 long-context reasoning에서 tri-mode 이점이 어떻게 스케일하는지 미검증.
  • Roleplay/writing 카테고리의 낮은 TPF: SOL 3.49/6.13, real self-spec은 그보다 더 낮음. 즉 open-ended generation에서는 tri-mode의 이점이 제한적이며, use case가 structured task에 편향.

확장 가능성

  • Nemotron-Labs-Diffusion은 Fast-dVLM과 같은 계열 (NVIDIA + 공저자 겹침 — Wu, Zhu, Xie 등)의 확장. Fast-dVLM이 "AR VLM → diffusion VLM 변환"이라면, 이 논문은 "AR LLM + diffusion LLM을 동시에". 향후 두 접근이 통합될 가능성.
  • Adaptive routing: 배포 시점에 concurrency와 task type을 감지해 자동으로 AR/diff/SS 모드 선택하는 controller. 논문에서는 수동 모드 선택만 다룸.
  • Diffusion-mode verification: 저자가 future work로 명시. AR verifier 대신 diffusion verifier를 쓰면 non-contiguous position들도 동시 검증 가능해 real TPF를 SOL에 더 가깝게 밀어붙일 수 있음.
  • Segment/paragraph-level parallelism: 현재는 token-level 병렬. 문단/문장 단위 병렬 예측을 학습하면 SOL 자체가 상승 가능.

Key Takeaways

  • ##AR과 diffusion은 서로 경쟁하는 대안이 아니라 상호 보완하는 objective##. $\alpha=0.3$에서 두 loss가 함께 개선되며, 이 발견은 향후 LM 학습의 default recipe로 유력. 특히 AR loss가 diffusion 학습에서 +7.48%로 최대 단일 개선을 제공한다는 사실은 이 커뮤니티에 큰 시사점.
  • ##Self-speculation (diffusion draft + AR verify)이 MTP (Eagle3 등) 보다 강력한 대안##. Full-capacity draft + token-parallel proposal 덕분에 acceptance length가 2× 이상. 실제 GB200에서 3.3× wall-clock 가속. 향후 LLM 서빙 인프라의 speculative decoding 표준이 될 잠재력.
  • Diffusion 모드의 SOL 상한 7.60× (real linear SS 대비 2× 이상)는 더 나은 sampler로 상당한 헤드룸이 남아있음을 정량화. 이는 향후 diffusion sampler 연구 커뮤니티에 명확한 목표를 제공.
  • 모델 스케일이 커질수록 diffusion/self-spec 이점 확대: 3B → 14B에서 linear SS TPF가 4.36× → 5.96×. 큰 모델일수록 미래 예측이 더 신뢰할 만하기 때문. Tri-mode의 이점은 scale-friendly.
  • VLM 확장이 자연스럽게 성립 — LM 파이프라인을 재사용하고 asymmetric dual-stream으로 vision FLOPs 절감. 이는 tri-mode 프레임워크가 modality-agnostic함을 시사.
  • ##Trained sampler (0.06%)와 LoRA drafter (0.4%) 같은 lightweight add-on이 acceptance length 30-40% 개선##을 제공. 이는 tri-mode 시스템에서 "얼마나 잘 align하는가"가 raw model 성능만큼이나 중요함을 보여줌.
